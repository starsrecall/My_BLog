# 如何退出nvim

在 Neovim 中，有几种退出方式：

## **标准退出步骤：**

### **1. 基本退出（无修改时）**
```
1. 按 `Esc` 键（确保你在正常模式）
2. 输入 `:q` （冒号 + 小写 q）
3. 按 `Enter` 键
```

### **2. 强制退出（有修改但不想保存）**
```
1. 按 `Esc` 键
2. 输入 `:q!` （冒号 + 小写 q + 感叹号）
3. 按 `Enter` 键
```

### **3. 保存并退出**
```
1. 按 `Esc` 键
2. 输入 `:wq` （冒号 + w + q）
3. 按 `Enter` 键
```
或者按 `Esc` 后输入 `ZZ`（两个大写 Z）

## **快速记忆：**
- **`:q`** = quit（退出）
- **`:q!`** = 强制退出（不保存）
- **`:wq`** = write and quit（保存并退出）

## **常见情况：**
- 如果你在输入文字（看到 `-- INSERT --`），先按 `Esc`
- 如果你看到一堆 `~` 符号和行号，那就是正常模式
- 如果输入 `:q` 后提示 `E37: No write since last change`，说明有修改，用 `:q!` 强制退出

## **额外技巧：**
- **`:qa`** = 退出所有打开的窗口/标签页
- **`:wqa`** = 保存所有并退出
- **按 `Ctrl+Z`** = 将 Neovim 放到后台（回到终端），然后用 `fg` 返回
