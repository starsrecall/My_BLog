# Hello, It’s Me

## 待解决问题
在名为`me`的文件夹中创建`hello.c`文件，用C语言实现一个程序，提示用户输入姓名，然后向该用户打招呼。例如，如果用户输入的姓名是Adele，程序应当打印`hello, Adele\n`。

---

## 提示

* 还记得吗？你可以通过`get_string`获取用户输入的**字符串（string）**，该函数声明在`cs50.h`中。
* 还记得吗？你可以通过`printf`打印字符串，该函数声明在`stdio.h`中。
* 还记得吗？你可以在`printf`中使用`%s`**格式化（format）**输出字符串。

---
## 操作入门
在**终端（Terminal）**窗口中单独执行`cd`命令，此时终端窗口的提示符应当类似如下内容：
```
$
```
接下来执行：
```
mkdir me
```
即可在你的**代码空间（Codespace）**中创建一个名为`me`的文件夹。
随后执行：

```
cd me
```
即可切换到该文件夹下，此时你看到的终端提示符应为`me/ $`。接下来执行：
```
code hello.c
```
即可创建名为`hello.c`的文件，你可以在该文件中编写代码。
