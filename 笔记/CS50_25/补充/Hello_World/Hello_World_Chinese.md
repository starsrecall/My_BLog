#include <stdio.h>
int main(void)

    printf("hello, world\n");

## 操作入门
在终端（Terminal）窗口中单独执行`cd`命令，此时终端窗口的提示符应当类似如下内容：
```
$
```
接下来执行：
```
mkdir world
```
即可在你的代码空间（Codespace）中创建一个名为`world`的文件夹。
随后执行：
```
cd world
```
即可切换到该文件夹下，此时你看到的终端提示符应为`world/ $`。接下来执行：
```
code hello.c
```
即可创建名为`hello.c`的文件，你可以在该文件中编写代码。

## 测试方法
你可以通过如下命令编译（Compile）`hello.c`：
```
make hello
```
如果没有看到报错信息，就说明编译成功！你也可以通过如下命令确认：
```
ls
```
该命令不仅会列出`hello.c`（即源代码（Source Code）），还会列出`hello`（即机器代码（Machine Code））。
如果确实看到报错信息，请尝试修复代码后重新编译。要是你看不懂报错信息，可以执行：
```
help50 make hello
```
来获取解决方案建议。
代码编译成功后，你可以通过如下命令执行程序：
```
./hello
```
### 正确性检查
执行以下命令，使用`check50`评估代码的正确性——这是一款命令行程序（Command-line Program），当你的代码通过CS50的自动化测试时会输出笑脸，未通过则输出哭脸！
```

```
### 代码风格检查
执行以下命令，使用`style50`评估代码风格——这是一款命令行程序，会标出你需要对程序做出的增加（绿色）和删除（红色）修改，以优化代码风格。如果你难以区分这些颜色，`style50`也支持其他[显示模式](https://cs50.readthedocs.io/style50/)！
```
style50 hello.c
```
