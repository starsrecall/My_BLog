# 马里奥（Mario）

## 待解决问题
在任天堂《超级马里奥兄弟》游戏1-1关的开头，马里奥需要跳过相邻的砖块金字塔，如下所示。

![马里奥跳过相邻砖块金字塔的截图](./mario_English.assets/pyramids.png)

请在名为`mario-more`的文件夹中创建`mario.c`文件，用C语言实现程序，复刻该金字塔结构，使用井号（`#`，英文称hash）作为砖块，效果如下：
```
   #  #
  ##  ##
 ###  ###
####  ####
```
程序需要首先提示用户输入1~8（含1和8）之间的正**整型（int）**数值，由用户指定金字塔的高度。

### 示例
若用户收到提示时输入`8`，程序运行效果如下：
```
$ ./mario
Height: 8
       #  #
      ##  ##
     ###  ###
    ####  ####
   #####  #####
  ######  ######
 #######  #######
########  ########
```

若用户输入`4`，效果如下：
```
$ ./mario
Height: 4
   #  #
  ##  ##
 ###  ###
####  ####
```

若用户输入`2`，效果如下：
```
$ ./mario
Height: 2
 #  #
##  ##
```

若用户输入`1`，效果如下：
```
$ ./mario
Height: 1
#  #
```

若用户未按要求输入1~8（含1和8）范围内的正整数，程序应当重新提示用户输入，直至用户输入符合要求为止：
```
$ ./mario
Height: -1
Height: 0
Height: 42
Height: 50
Height: 4
   #  #
  ##  ##
 ###  ###
####  ####
```

注意：相邻金字塔之间的**间隙（gap）**宽度固定为2个井号的宽度，与金字塔的高度无关。

【难句解析】
1. 原文：Toward the beginning of World 1-1 in Nintendo’s Super Mario Brothers, Mario must hop over adjacent pyramids of blocks, per the below.
   译文：在任天堂《超级马里奥兄弟》游戏1-1关的开头，马里奥需要跳过相邻的砖块金字塔，如下所示。
   解析：本句为场景引入句，翻译时调整了英文的前置状语语序，先说明游戏背景，再描述核心场景，符合中文叙事逻辑；将游戏玩家通用的“World 1-1”译为“1-1关”，“per the below”译为中文技术文档常用的“如下所示”，避免生硬直译。
2. 原文：Notice that width of the “gap” between adjacent pyramids is equal to the width of two hashes, irrespective of the pyramids’ heights.
   译文：注意：相邻金字塔之间的间隙宽度固定为2个井号的宽度，与金字塔的高度无关。
   解析：本句是程序实现的核心规则，翻译时添加“固定”二字突出规则的强制性，避免学习者误解间隙宽度会随高度变化；将“irrespective of”译为“与…无关”，符合中文技术文档的严谨表达，明确规则的适用条件。
3. 原文：If the user doesn’t, in fact, input a positive integer between 1 and 8, inclusive, when prompted, the program should re-prompt the user until they cooperate.
   译文：若用户未按要求输入1~8（含1和8）范围内的正整数，程序应当重新提示用户输入，直至用户输入符合要求为止。
   解析：本句为输入校验规则，将插入语“in fact”意译为“按要求”，符合操作指引的正式语气；“inclusive”补充标注为（含1和8），清晰明确边界值要求；“cooperate”没有直译为“配合”，而是结合场景译为“输入符合要求”，避免口语化，同时准确还原规则含义。
4. 原文：Does your code work as prescribed when you input * `-1` (or other negative numbers)? ... * no input at all, when you only hit Enter?
   译文：你可以输入以下场景的内容，验证代码是否符合要求：* `-1`（或其他负数）？... * 不输入任何内容，直接按下回车？
   解析：原句为反问句式的测试指引，翻译时调整为中文常用的陈述式操作指引，更符合测试环节的表达习惯；“hit Enter”译为开发者通用的“按下回车”，符合国内技术文档的常用表述。
