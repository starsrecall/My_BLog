## 示例

下面文本可以来制作一份流程图

```tex

```mermaid
graph TD
  	A((开始))-->B[任务A]
  	B[任务A]-->C[任务B]
  	C[任务B]-->D{判断}
  	D{判断}-->|是|E((结束))
  	D{判断}-->|否|B[任务A]
```



**结果如下**


```mermaid
graph TD
  	A((开始))-->B[任务A]
  	B[任务A]-->C[任务B]
  	C[任务B]-->D{判断}
  	D{判断}-->|是|E((结束))
  	D{判断}-->|否|B[任务A]
```

## 流程图的符号

| 符号名称                | 图形表示                 | 核心用途                                       | 补充说明                                                     |
| :---------------------- | :----------------------- | :--------------------------------------------- | :----------------------------------------------------------- |
| **起止符**              | 圆角矩形/跑道形/椭圆形   | 表示流程的**开始**或**结束**                   | 通常在一个流程图中，**开始符号只能有一个**，结束符号可以有多个。内部一般标注“开始”或“结束”。 |
| **处理/过程符**         | **矩形**                 | 表示一个具体的**操作步骤或处理过程**           | 这是流程图中最常用、出现频率最高的符号。                     |
| **判断/决策符**         | **菱形**                 | 表示需要做出**决策或判断**的分支节点           | 通常有一个入口，至少两个出口。                               |
| **输入/输出符**         | **平行四边形**           | 表示数据的**输入**或**输出**                   | 可以泛指任何类型的I/O操作。                                  |
| **流程线**              | **带箭头的线**           | 表示各步骤之间的**顺序和流向**                 | 箭头方向至关重要，标准流向是**从上到下，从左到右**。         |
| **连接符**              | **圆形**                 | 用于**避免流程线过长或交叉**                   | 相同标识（如字母或数字）的连接符表示流程在此处衔接。**必须成对出现**，不能只有一个。 |
| **注释符**              | 括号或虚线矩形           | 对某个步骤进行**补充说明**                     | 它只起解释作用，**不是流程的逻辑环节**，不影响流程走向。     |
| **子流程/预定义过程符** | 矩形左右两边为双竖线     | 表示一个**已经定义好或在别处展开的详细子流程** | 用于简化主流程图，使逻辑更清晰。例如，在“订单处理”主流程中，“验证支付”可作为一个子流程符号。 |
| **并行符**              | 双杠矩形或分叉/汇合线    | 表示**多个可以同时进行的步骤**                 | 常用于描述可以并发处理的任务，之后再进行汇合，能有效节省总流程时间。 |
| **延迟符**              | 圆角矩形带波浪线或沙漏形 | 表示流程中的**等待状态**                       | 明确标注出非人为操作的时间间隔，如“等待客户确认”、“等待系统响应”。 |
| **终止符**              | 粗体椭圆形               | 表示流程**异常或强制终止**                     | 与正常的结束符区分，用于标识因错误、拒绝等原因导致流程无法正常完成的情况。 |

## 布局方向



| 方向标识  | 含义                      | 说明                               |
| :-------- | :------------------------ | :--------------------------------- |
| **TB/TD** | 从上到下（Top to Bottom） | 节点按从上到下的顺序排列，最常用。 |
| **BT**    | 从下到上（Bottom to Top） | 节点按从下到上的顺序排列。         |
| **LR**    | 从左到右（Left to Right） | 节点按从左到右的顺序排列。         |
| **RL**    | 从右到左（Right to Left） | 节点按从右到左的顺序排列。         |

> 注意：用大写英文字母表示方向

### 方向朝下(TB/TD)（from **T**op to **B**ottom）

**源码**

```tex
graph TB
    Start --> Stop
```

**效果**

```mermaid
graph TB
	    Start --> Stop
```



### 方向朝上（BT）(from **B**ottom to **T**op)

**源码**
```tex
graph BT
    Start --> Stop
```

**效果**
```mermaid
graph BT
    Start --> Stop
```

### 方向朝右（LR）( from **L**eft to **R**ight)

**源码**
```tex
graph LR
    Start --> Stop
```

**效果**
```mermaid
graph LR
    Start --> Stop
```

### 方向朝左（RL）(**R**ight to **L**eft)

**源码**
```tex
graph RL
    Start --> Stop
```

**效果**
```mermaid
graph RL
    Start --> Stop
```

## 连接线

### 局限

- **无法手动调整**：Mermaid 不支持手动指定连接线的具体端点位置（如左上角），但可以通过子图或隐形节点辅助调整(闲的)。





### 1. 基础连接线语法

最基本的连接线由箭头 `-->` 表示，连接两个节点 ID。

```tex
```mermaid
	graph LR
		A1-->B1
		A2-->|是|B2
```

```mermaid
	graph LR
		A1-->B1
		A2-->|是|B2
```

### 2. 连接线的类型

Mermaid 支持多种线型，可以通过改变符号组合实现。

| 线型             | 语法   | 示例效果   | 说明                                             |
| :--------------- | :----- | :--------- | :----------------------------------------------- |
| **带箭头实线**   | `-->`  | `A --> B`  | 最常用，表示单向流向。                           |
| **不带箭头实线** | `---`  | `A --- B`  | 仅表示连接，无方向，常用于关系图，流程图较少用。 |
| **带箭头粗线**   | `==>`  | `A ==> B`  | 强调流向，可用于突出主路径。                     |
| **不带箭头粗线** | `===`  | `A === B`  | 粗实线无箭头，少见。                             |
| **带箭头虚线**   | `-.->` | `A -.-> B` | 常用于表示可选路径、备选流程或注释关联。         |
| **不带箭头虚线** | `-.-`  | `A -.- B`  | 常用于注释连接（如之前的注释节点）。             |

**示例：**

```tex
```mermaid
	graph LR
		A1-->B1
		A2---B2
		A3==>B3
		A4===B4
		A5-.->B5
		A6-.-B6
```

```mermaid
	graph LR
		A1-->B1
		A2---B2
		A3==>B3
		A4===B4
		A5-.->B5
		A6-.-B6
```






### 3. 在连接线上添加文本

文本可以放在箭头上方，用 `|` 包裹，也可以放在箭头中间或末尾。

- **标准位置（箭头中间）**：`A -->|文本| B`
- **箭头末尾**：`A -- 文本 --> B` （效果同 `A -->|文本| B`）
- **长文本换行**：换行符 `<br/>`，但需渲染环境支持。



```tex
```mermaid
	graph LR
		A1 -->|文本| B1
		A2 -- 文本 --> B2
		A3 -- 文本<br/>文本 --> B3
```

```mermaid
	graph LR
		A1 -->|文本| B1
		A2 -- 文本 --> B2
		A3 -- 文本<br/>文本 --> B3
```




### 4. 连接线的长度与换行

Mermaid 会自动计算连接线长度，但可以通过增加箭头符号来强制延长。

- `-->` 短连接
- `--->` 较长连接
- `---->` 更长连接

```tex
```mermaid
	graph LR
		A1 -->|短连接| B1
		A2  --->|较长连接| B2
		A3  ----->|更长连接| B3
```

```mermaid
	graph LR
		A1 -->|短连接| B1
		A2  --->|较长连接| B2
		A3  ----->|更长连接| B3
```




### 5. 多重连接与并行

- **多个节点指向同一节点**：`A --> C & B --> C` 也可以写成 `A & B --> C`
- **一个节点指向多个节点**：`A --> B & A --> C` 也可以写成 `A --> B & C`

这种写法常用于表示并行处理。

```tex
graph LR
    Start --> Task1 & Task2  
    Task1 & Task2 --> End     
```



```mermaid
graph LR
    Start --> Task1 & Task2  
    Task1 & Task2 --> End   
```







### 6. 链式连接

可以连续写出多个连接，Mermaid 会自动串联。

```tex
graph LR
    A-->B-->C-->D  
```


```mermaid
graph LR
  A-->B-->C-->D  
```








### 7. 连接线的箭头

默认情况下，连接线会自动选择节点上的合适位置（上、下、左、右）连接。如果需要精确控制连接点，可以在节点 ID 后附加端口方向：

- `A-->B` 默认
- `A--o B` 圆圈箭头
- `A--x B` 叉号箭头


```tex
graph LR
   A1-->|默认|B1
   A2--o|圆圈箭头|B2
   A3--x|叉号箭头|B2
```


```mermaid
graph LR
   A1-->|默认|B1
   A2--o|圆圈箭头|B2
   A3--x|叉号箭头|B3 
```



### 8.扩展

连接线可以跨子图连接节点，但注意子图的边界可能会影响布局。

```tex
```mermaid
graph TB
    subgraph 子图1
        A[节点A]
    end
    subgraph 子图2
        B[节点B]
    end
    A --> B  
```





```mermaid
graph TB
    subgraph 子图1
        A[节点A]
    end
    subgraph 子图2
        B[节点B]
    end
    A --> B  
    
```

## 一些小问题

引用[官方文档](https://mermaid.nodejs.cn/syntax/flowchart.html)

>警告:如果你在流程图节点中使用“end”这个词，请将整个单词或任意字母大写（例如，“End”或“END”），或者使用这个[解决方法](https://github.com/mermaid-js/mermaid/issues/1444#issuecomment-639528897)。全部小写输入“end”会导致流程图出错。
