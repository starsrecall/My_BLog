## 初级核心语法

### 希腊字母

希腊字母是数学、物理、工程等领域公式中最常用的符号，LaTeX中的希腊字母命令大多是英文音译，小写字母命令开头小写，大写字母命令开头大写，部分字母有常用变体，具体如下表：

| 小写字母 | LaTeX命令                     | 大写字母 | LaTeX命令                     | 变体字母      | LaTeX命令     | 常用场景                 |
| -------- | ----------------------------- | -------- | ----------------------------- | ------------- | ------------- | ------------------------ |
| α        | `\alpha`                      | Α        | `\Alpha`（和A相同，极少用）   | ε（半开口）   | `\varepsilon` | 角度、无穷小量、介电常数 |
| β        | `\beta`                       | Β        | `\Beta`（和B相同，极少用）    | ϵ（全开口）   | `\epsilon`    | 角度、回归系数           |
| γ        | `\gamma`                      | Γ        | `\Gamma`                      | -             | -             | 欧拉常数、伽马函数、电导 |
| δ        | `\delta`                      | Δ        | `\Delta`                      | -             | -             | 微分量、差分、判别式     |
| ζ        | `\zeta`                       | Ζ        | `\Zeta`（和Z相同，极少用）    | -             | -             | 黎曼ζ函数、阻尼系数      |
| η        | `\eta`                        | Η        | `\Eta`（和H相同，极少用）     | -             | -             | 效率、黏度               |
| θ        | `\theta`                      | Θ        | `\Theta`                      | ϑ（斜体变体） | `\vartheta`   | 角度、温度               |
| ι        | `\iota`                       | Ι        | `\Iota`（和I相同，极少用）    | -             | -             | 单位矩阵、指标           |
| κ        | `\kappa`                      | Κ        | `\Kappa`（和K相同，极少用）   | -             | -             | 热导率、介电常数         |
| λ        | `\lambda`                     | Λ        | `\Lambda`                     | -             | -             | 波长、特征值             |
| μ        | `\mu`                         | Μ        | `\Mu`（和M相同，极少用）      | -             | -             | 摩擦系数、微、期望       |
| ν        | `\nu`                         | Ν        | `\Nu`（和N相同，极少用）      | -             | -             | 频率、中微子             |
| ξ        | `\xi`                         | Ξ        | `\Xi`                         | -             | -             | 随机变量、特征函数       |
| ο        | `\omicron`（和o相同，极少用） | Ο        | `\Omicron`（和O相同，极少用） | -             | -             | 高阶小量                 |
| π        | `\pi`                         | Π        | `\Pi`                         | ϖ（变体）     | `\varpi`      | 圆周率、连乘积           |
| ρ        | `\rho`                        | Ρ        | `\Rho`（和P相同，极少用）     | ς（变体）     | `\varrho`     | 密度、电阻率             |
| σ        | `\sigma`                      | Σ        | `\Sigma`                      | -             | -             | 标准差、应力、求和       |
| τ        | `\tau`                        | Τ        | `\Tau`（和T相同，极少用）     | -             | -             | 时间常数、转矩           |
| υ        | `\upsilon`                    | Υ        | `\Upsilon`                    | -             | -             | 宇称、速率               |
| φ        | `\phi`                        | Φ        | `\Phi`                        | φ（圆头变体） | `\varphi`     | 电势、相位、欧拉函数     |
| χ        | `\chi`                        | Χ        | `\Chi`（和X相同，极少用）     | -             | -             | 卡方分布、电极化率       |
| ψ        | `\psi`                        | Ψ        | `\Psi`                        | -             | -             | 波函数、角度             |
| ω        | `\omega`                      | Ω        | `\Omega`                      | -             | -             | 角速度、电阻单位、角频率 |

- **常用场景示例**：
  1. 三角恒等式：$\sin(\alpha + \beta) = \sin\alpha \cos\beta + \cos\alpha \sin\beta$，写法：`$\sin(\alpha + \beta) = \sin\alpha \cos\beta + \cos\alpha \sin\beta$`
  2. 物理公式：角速度$\omega$、波长$\lambda$、电阻单位$\Omega$、效率$\eta$
  3. 数学常量：圆周率$\pi \approx 3.14159$、欧拉常数$\gamma \approx 0.5772$
- **注意事项**：
  1. 大写希腊字母如果和英文字母形状相同，不需要用LaTeX命令，直接写英文字母即可，比如`\Alpha`就是A，直接写A更简洁。
  2. 希腊字母默认是斜体，符合学术规范，如果需要正体希腊字母，可以用`\mathrm{\alpha}`包裹，部分平台支持`upgreek`包的`\upalpha`命令实现正体，但兼容性较低，优先使用`\mathrm`。
  3. 注意变体字母的学科使用习惯：数学中通常用`\varepsilon`表示无穷小量，用`\epsilon`表示介电常数；用`\varphi`表示角度或欧拉函数，用`\phi`表示电势，避免混用导致歧义。

### 上下标与装饰标记

上下标是几乎所有公式都会用到的功能，装饰标记用来给字符添加帽子、横线、箭头等注释，是新手犯错频率最高的语法模块。

#### 基础上下标语法

- 上标：使用`^`符号，后面跟上标内容
- 下标：使用`_`符号，后面跟下标内容
- **核心分组规则**：如果上下标的内容多于1个字符，必须用花括号`{}`包裹，否则渲染器只会把`^`或`_`后面的第一个字符识别为上下标内容，这是新手最容易犯的错误！
  错误与正确写法对比：

| 预期效果    | 错误写法 | 错误渲染效果 | 正确写法   | 正确渲染效果 |
| ----------- | -------- | ------------ | ---------- | ------------ |
| x的10次方   | `x^10`   | $x^10$       | `x^{10}`   | $x^{10}$     |
| a的下标i+j  | `a_i+j`  | $a_i+j$      | `a_{i+j}`  | $a_{i+j}$    |
| e的x²次方   | `e^x^2`  | 渲染异常     | `e^{x^2}`  | $e^{x^2}$    |
| 10的a+b次方 | `10^a+b` | $10^a+b$     | `10^{a+b}` | $10^{a+b}$   |

- **多重上下标规则**：
  1. 上标可以嵌套上标：$x^{y^{z^2}}$，写法：`x^{y^{z^2}}`，每一层嵌套都需要用`{}`包裹
  2. 下标可以嵌套下标：$a_{b_{c_d}}$，写法：`a_{b_{c_d}}`
  3. 上下标可以同时使用，顺序不影响渲染效果：`x_1^2`和`x^2_1`都会渲染为$x_1^2$
- **特殊上下标用法**：
  1. 撇号：表示导数或者矩阵转置，可以直接用`'`符号，比如$a'$、$a''$、$a'''$，等价于`a^{\prime}`、`a^{\prime\prime}`、`a^{\prime\prime\prime}`，直接写`'`更简洁。
  2. 角标位置调整：如果需要把上下标放在符号的左上角/左下角，可以用`\prescript{上}{下}{符号}`命令，比如$\prescript{*}{H}{A}$表示矩阵A的共轭转置，写法：`\prescript{*}{H}{A}`；老旧平台不支持该命令的话，可以用`{}_H^*A`实现类似效果：${}_H^*A$。

### 常用装饰标记

装饰标记用来给字符添加额外注释，比如表示向量、平均值、线段、范围等，按照适用场景分为单字符装饰和多字符装饰两大类，新手需要特别注意短装饰和长装饰的适用范围，避免出现覆盖不全的排版问题。

#### （1）单字符装饰（仅覆盖单个字符）
这类装饰命令默认仅作用于紧随其后的单个字符，适合给单个变量、希腊字母添加标记，语法简单、排版紧凑，是最常用的装饰类型，常用命令如下表：
| 装饰类型         | LaTeX命令       | 渲染效果        | 适用场景                           | 注意事项                                              |
| ---------------- | --------------- | --------------- | ---------------------------------- | ----------------------------------------------------- |
| 短横线（平均值） | `\bar{x}`       | $\bar{x}$       | 单变量的平均值、样本均值、共轭复数 | 仅覆盖单个字符，多字符需用`\overline`                 |
| 短波浪线         | `\tilde{x}`     | $\tilde{x}$     | 随机变量的估计值、修正量、近似值   | 多字符需用`\widetilde`                                |
| 短帽子           | `\hat{x}`       | $\hat{x}$       | 参数的估计量、单位向量、算符       | 多字符需用`\widehat`                                  |
| 向量短箭头       | `\vec{x}`       | $\vec{x}$       | 单字符的向量表示                   | 多字符向量需用`\overrightarrow`                       |
| 一阶导数点       | `\dot{x}`       | $\dot{x}$       | 物理中对时间的一阶导数、变化率     | 二阶导数用`\ddot{x}`（$\ddot{x}$），三阶用`\dddot{x}` |
| 尖重音           | `\acute{x}`     | $\acute{x}$     | 数学中的锐音标记、特殊变量         | 极少使用，仅需了解                                    |
| 钝重音           | `\grave{x}`     | $\grave{x}$     | 数学中的钝音标记、特殊变量         | 极少使用，仅需了解                                    |
| 下划线           | `\underline{x}` | $\underline{x}$ | 强调变量、线段表示、下界           | 多字符下划线也可直接使用该命令                        |

*错误示例对比*：如果错误地将单字符装饰用于多字符内容，会出现仅覆盖第一个字符的问题：
| 预期效果    | 错误写法      | 错误渲染      | 正确写法              | 正确渲染              |
| ----------- | ------------- | ------------- | --------------------- | --------------------- |
| xy的平均值  | `\bar{xy}`    | $\bar{xy}$    | `\overline{xy}`       | $\overline{xy}$       |
| AB的向量    | `\vec{AB}`    | $\vec{AB}$    | `\overrightarrow{AB}` | $\overrightarrow{AB}$ |
| abc的估计量 | `\hat{abc}`   | $\hat{abc}$   | `\widehat{abc}`       | $\widehat{abc}$       |
| xyz的修正值 | `\tilde{xyz}` | $\tilde{xyz}$ | `\widetilde{xyz}`     | $\widetilde{xyz}$     |

#### （2）多字符装饰（覆盖任意长度内容）
这类装饰命令会自动适配内容的长度，适合给长表达式、多个字符添加标记，还支持添加自定义注释，是复杂公式排版的常用工具：
##### ① 上下大括号注释
使用`\overbrace{内容}^{上注释}`添加上方带注释的大括号，使用`\underbrace{内容}_{下注释}`添加下方带注释的大括号，支持多层嵌套，适合标注公式的组成部分、项数范围等：
- 基础示例：标注求和项的数量
  ```latex
  \overbrace{1+2+3+\dots+n}^{n个正整数} = \frac{n(n+1)}{2}
  ```
  渲染效果：
  $$
  \overbrace{1+2+3+\dots+n}^{n个正整数} = \frac{n(n+1)}{2}
  $$
- 嵌套示例：同时标注多个部分
  ```latex
  \underbrace{\overbrace{a+b}^{两项和} + \overbrace{c+d+e}^{三项和}}_{共5项} = S
  ```
  渲染效果：
  $$
  \underbrace{\overbrace{a+b}^{两项和} + \overbrace{c+d+e}^{三项和}}_{共5项} = S
  $$
- 行内适配：行内公式中使用大括号时，注释会自动调整大小避免撑大行距：
  行内写法：`数列$\underbrace{a_1,a_2,\dots,a_k}_{前k项}$的和为$S_k$`
  渲染效果：数列$\underbrace{a_1,a_2,\dots,a_k}_{前k项}$的和为$S_k$

##### ② 箭头与符号注释
- `\stackrel{上标记}{基础符号}`：在任意符号上方添加小型标记，适合定义特殊运算符：
  示例：定义“等于”为“定义等价”：
  ```latex
  A \stackrel{\Delta}{=} B \quad \text{表示A定义为B}
  ```
  渲染效果：$A \stackrel{\Delta}{=} B \quad \text{表示A定义为B}$
- `\xrightarrow{上标记}[下标记]`：生成可自适应长度的右箭头，上下可添加自定义标注，适合表示极限、映射、反应过程：
  示例1：极限过程标注：
  ```latex
  a_n \xrightarrow{n \to \infty} 0
  ```
  渲染效果：$a_n \xrightarrow{n \to \infty} 0$
  示例2：化学反应标注：
  ```latex
  2H_2 + O_2 \xrightarrow{点燃} 2H_2O
  ```
  渲染效果：$2H_2 + O_2 \xrightarrow{点燃} 2H_2O$
  左箭头对应命令为`\xleftarrow`，双向箭头为`\xleftrightarrow`，用法完全一致。

### 运算符号

运算符号是公式的核心组成部分，LaTeX提供了符合国际学术出版规范的全套运算符号，新手需要避免直接使用键盘上的不规范符号（比如用`>=`代替`≥`、用`*`代替乘号），否则会导致公式排版不专业、可读性差。按照用途可将常用运算符号分为六大类：

#### 基础四则运算符号

除了最基础的`+`（加）、`-`（减）之外，LaTeX提供了规范的乘、除、正负、阶乘等符号，需要根据场景选择合适的写法：
| 符号含义     | LaTeX命令           | 渲染效果            | 适用场景                       | 注意事项                                                     |
| ------------ | ------------------- | ------------------- | ------------------------------ | ------------------------------------------------------------ |
| 叉乘（外积） | `\times`            | $\times$            | 数字相乘、向量叉乘、笛卡尔积   | 变量相乘尽量不用`\times`，避免和字母x混淆                    |
| 点乘（内积） | `\cdot`             | $\cdot$             | 变量相乘、向量内积、数乘       | 多个变量相乘也可直接省略乘号，比如$ab$表示$a\cdot b$         |
| 除号         | `\div`              | $\div$              | 小学、中学数学的除法表示       | 学术写作中几乎不用`\div`，优先用分式或`/`表示                |
| 正负号       | `\pm`               | $\pm$               | 误差范围、二次方程求根的正负根 | 负正号用`\mp`（$\mp$），和`\pm`顺序相反                      |
| 阶乘         | `!`                 | $n!$                | 阶乘运算                       | 双阶乘用`!`，比如$(2n)!=2\times4\times\dots\times2n$         |
| 绝对值       | `\lvert x \rvert`   | $\lvert x \rvert$   | 绝对值、复数模长               | 不要直接用键盘的`|`，嵌套时大小不会自适应，详见2.6节定界符内容 |
| 范数         | `\lVert x \rVert`   | $\lVert x \rVert$   | 向量范数、矩阵范数             | 同样不要直接用两个`||`，排版间距错误                         |
| 上取整       | `\lceil x \rceil`   | $\lceil x \rceil$   | 不小于x的最小整数              | 比如$\lceil 1.2 \rceil = 2$                                  |
| 下取整       | `\lfloor x \rfloor` | $\lfloor x \rfloor$ | 不大于x的最大整数              | 比如$\lfloor 1.2 \rfloor = 1$                                |
| 开平方       | `\sqrt{x}`          | $\sqrt{x}$          | 平方根运算                     | 不要写成`x^{1/2}`，可读性差                                  |
| 开n次方      | `\sqrt[n]{x}`       | $\sqrt[n]{x}$       | n次方根运算                    | 根次放在`[]`中，不要放在`{}`里，错误写法`\sqrt{n}{x}`会渲染为$\sqrt{n}{x}$ |

*重点注意*：自然常数$\mathrm{e}$、圆周率$\pi$、虚数单位$\mathrm{i}$属于常数，按照学术规范需要用正体表示，正确写法为`\mathrm{e}`（$\mathrm{e}$）、`\pi`（$\pi$）、`\mathrm{i}`（$\mathrm{i}$），不要写成斜体的$e$、$i$，避免和变量混淆。

#### 2.3.2 关系运算符
关系运算符用于表示两个表达式之间的逻辑关系，排版时会自动在左右添加合适的间距，不要直接用键盘上的替代符号：
| 符号含义      | LaTeX命令 | 渲染效果  | 注意事项                                        |
| ------------- | --------- | --------- | ----------------------------------------------- |
| 等于          | `=`       | $=$       | 基础等于符号，无需额外命令                      |
| 不等于        | `\neq`    | $\neq$    | 不要用`<>`或`!=`，不符合学术规范                |
| 恒等于        | `\equiv`  | $\equiv$  | 用于恒等式、同余关系                            |
| 约等于        | `\approx` | $\approx$ | 近似相等，渐进相等用`\simeq`（$\simeq$）        |
| 同构/全等     | `\cong`   | $\cong$   | 用于几何全等、代数同构                          |
| 相似/服从分布 | `\sim`    | $\sim$    | 比如$X \sim N(0,1)$表示X服从正态分布            |
| 正比于        | `\propto` | $\propto$ | 表示两个变量成正比例关系                        |
| 大于          | `>`       | $>$       | 基础大于符号                                    |
| 小于          | `<`       | $<$       | 基础小于符号                                    |
| 大于等于      | `\geq`    | $\geq$    | 不要用`>=`，排版不规范                          |
| 小于等于      | `\leq`    | $\leq$    | 不要用`<=`，排版不规范                          |
| 远大于        | `\gg`     | $\gg$     | 表示量级差距极大，比如$\alpha \ll 1$表示α是小量 |
| 远小于        | `\ll`     | $\ll$     | 用法同远大于                                    |

#### 集合运算符

集合论相关的运算符是数学、计算机科学领域的常用符号，需要注意空集和希腊字母$\phi$的区别：
| 符号含义 | LaTeX命令     | 渲染效果      | 注意事项                                                 |
| -------- | ------------- | ------------- | -------------------------------------------------------- |
| 属于     | `\in`         | $\in$         | 表示元素属于集合，不要用手写的属于符号                   |
| 不属于   | `\notin`      | $\notin$      | 不要写成`\not\in`，排版更紧凑                            |
| 子集     | `\subseteq`   | $\subseteq$   | 表示包含于，允许两个集合相等                             |
| 真子集   | `\subsetneq`  | $\subsetneq$  | 表示真包含于，不允许相等，避免用含义模糊的`\subset`      |
| 超集     | `\supseteq`   | $\supseteq$   | 表示包含，对应子集的反向                                 |
| 真超集   | `\supsetneq`  | $\supsetneq$  | 表示真包含，对应真子集的反向                             |
| 并集     | `\cup`        | $\cup$        | 两个集合的并集，大型并集用`\bigcup`（见2.5节大型运算符） |
| 交集     | `\cap`        | $\cap$        | 两个集合的交集，大型交集用`\bigcap`（见2.5节大型运算符） |
| 集合差   | `\setminus`   | $\setminus$   | 比如$A \setminus B$表示A中去掉B的元素，不要用`-`代替     |
| 空集     | `\emptyset`   | $\emptyset$   | 不要用希腊字母`\phi`（$\phi$），二者形状和含义完全不同   |
| 补集     | `\complement` | $\complement$ | 表示集合的补集，也可写作`A^c`（$A^c$）                   |

#### 逻辑运算符

逻辑运算符是证明、离散数学、计算机科学领域的常用符号，LaTeX提供了标准的排版形式：
| 符号含义 | LaTeX命令    | 渲染效果     | 注意事项                                                   |
| -------- | ------------ | ------------ | ---------------------------------------------------------- |
| 任意     | `\forall`    | $\forall$    | 全称量词，不要用倒写的A手写符号                            |
| 存在     | `\exists`    | $\exists$    | 存在量词，不要用反写的E手写符号                            |
| 不存在   | `\nexists`   | $\nexists$   | 表示不存在满足条件的元素                                   |
| 与（且） | `\land`      | $\land$      | 逻辑与运算，也可用`\wedge`（$\wedge$）                     |
| 或       | `\lor`       | $\lor$       | 逻辑或运算，也可用`\vee`（$\vee$）                         |
| 非       | `\neg`       | $\neg$       | 逻辑非运算，不要用`!`代替                                  |
| 蕴含     | `\implies`   | $\implies$   | 表示“如果…则…”，也可用`\Rightarrow`（$\Rightarrow$）       |
| 当且仅当 | `\iff`       | $\iff$       | 表示充要条件，也可用`\Leftrightarrow`（$\Leftrightarrow$） |
| 所以     | `\therefore` | $\therefore$ | 证明中表示结论推导                                         |
| 因为     | `\because`   | $\because$   | 证明中表示推导依据                                         |

#### 微积分与算子符号

微积分、物理、工程领域常用的算子符号需要注意正体规范，避免写成斜体：
| 符号含义     | LaTeX命令    | 渲染效果     | 注意事项                                                     |
| ------------ | ------------ | ------------ | ------------------------------------------------------------ |
| 微分算子     | `\mathrm{d}` | $\mathrm{d}$ | 微分符号d必须用正体，正确写法$\mathrm{d}x$，不要写斜体的$dx$ |
| 偏微分算子   | `\partial`   | $\partial$   | 偏导数符号，比如偏导数$\frac{\partial f}{\partial x}$        |
| 梯度算子     | `\nabla`     | $\nabla$     | 哈密顿算子，梯度$\nabla f$、散度$\nabla \cdot \boldsymbol{f}$、旋度$\nabla \times \boldsymbol{f}$ |
| 拉普拉斯算子 | `\Delta`     | $\Delta$     | 注意和判别式$\Delta$是同一个符号，根据上下文区分             |
| 模运算       | `\pmod{n}`   | $\pmod{n}$   | 同余表达式，比如$a \equiv b \pmod{n}$，单独的模用`\bmod`（$\bmod$） |
| 迹           | `\tr`        | $\tr$        | 矩阵的迹，内置命令自动为正体，不要写`tr`                     |
| 行列式       | `\det`       | $\det$       | 矩阵的行列式，内置命令自动为正体                             |
| 秩           | `\rank`      | $\rank$      | 矩阵的秩，内置命令自动为正体                                 |

*重点提醒*：所有的函数名、算子名LaTeX都提供了内置的正体命令，比如`\sin`、`\cos`、`\log`、`\ln`、`\exp`、`\max`、`\min`、`\lim`等，直接使用即可，不要手动拼写，比如`\sin x`渲染为$\sin x$（规范正体），而手动写`sin x`会渲染为$sin x$（斜体、间距错误，非常不规范）。常用的内置函数命令超过50个，涵盖了几乎所有基础数学场景，遇到不确定的可以直接查LaTeX函数命令表。

### 分式与根式：排版美观的核心细节

分式和根式是新手最容易出现排版问题的语法点，尤其是行内和块级公式中的大小适配、多层嵌套的对齐问题，掌握核心规则后可以轻松写出美观的表达式。
