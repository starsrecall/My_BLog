###  公式的两种基础插入模式

LaTeX公式分为行内公式和块级公式两种模式，分别适配不同的使用场景，语法和注意事项差异较大。

#### 1 行内公式（Inline Formula）

行内公式嵌入在正文段落中，和文字融为一体，适合表述简单的变量、常量、短公式。
- **通用语法**：用`$...$`包裹公式内容，是所有平台都支持的标准写法；部分平台也支持LaTeX原生的`\( ... \)`语法，但兼容性较低，不推荐使用。
- **示例**：
  原文写法：`圆的面积公式为$S = \pi r^2$，其中$r$为圆的半径，$\pi$为圆周率，取值约为$3.14159$。`
  渲染效果：圆的面积公式为$S = \pi r^2$，其中$r$为圆的半径，$\pi$为圆周率，取值约为$3.14159$。
- **核心注意事项**：
  1. **$配对问题**：`$`必须成对出现，否则渲染器会将后续所有内容识别为公式，导致整个段落渲染异常。新手常犯的错误是漏写结尾的`$`，排查时可以优先检查配对情况。
  2. **货币符号冲突**：如果正文需要使用美元符号，比如`本次活动预算为100$`，必须对`$`转义写成`100\$`，否则渲染器会将`$`识别为行内公式的开头，导致后续内容排版混乱。
  3. **字体大小适配**：行内公式默认使用小字号，避免撑大段落行高，如果需要在行内突出显示大尺寸的分式、求和符号，可以使用`\dfrac`、`\sum\limits`等强制大尺寸命令。
  4. **空格规则**：`$`和内部公式内容之间不需要加空格，`$`和外部正文之间的空格不影响渲染，比如`$S=\pi r^2$`和` $S=\pi r^2$ `的渲染效果完全一致。

#### 2 块级公式（Display Formula）

块级公式独立成段，默认居中显示，适合展示重要定理、推导结果、方程组、复杂公式等需要突出的内容，有三种主流写法：
1. **双$包裹法**：`$$...$$`，是最通用的块级公式语法，所有平台都支持，适合大多数场景。
2. **Fenced代码块法**：用```` ```math ````开头、```` ``` ````结尾包裹公式，是GFM推出的标准语法，避免了双`$`和其他标记的冲突，兼容性越来越好，优先推荐使用。
3. **方括号包裹法**：`\[ ... \]`，是LaTeX原生语法，仅部分平台支持，兼容性最低，不推荐使用。
- **示例1：双$写法**
  原文写法：
  ```
  勾股定理的表达式为：
  
  $$
  a^2 + b^2 = c^2
  $$
  
  其中$a,b$为直角边的长度，$c$为斜边的长度。
  ```
  渲染效果：
  勾股定理的表达式为：

  $$
  a^2 + b^2 = c^2
  $$

  其中$a,b$为直角边的长度，$c$为斜边的长度。
- **示例2：Fenced代码块写法**
  原文写法：
  ```
  二次方程的求根公式为：
  
  ```math
  x = \frac{-b \pm \sqrt{b^2 - 4ac}}{2a}
  ```

  其中$a \neq 0$，$\Delta = b^2 - 4ac$为判别式。
  ```
  渲染效果：
  二次方程的求根公式为：
  
  $$
  x = \frac{-b \pm \sqrt{b^2 - 4ac}}{2a}
  $$
  
  其中$a \neq 0$，$\Delta = b^2 - 4ac$为判别式。
- **核心注意事项**：
  1. **空行要求**：90%以上的平台要求块级公式的前后必须有空行，否则会被识别为行内公式或者普通文本。比如`二次方程的求根公式为：$$x = ...$$`这种写法没有空行，绝大多数平台会渲染失败，必须在`$$`或者```` ```math ````的前后各加一个空行，和正文内容分隔开。
  2. **块内换行**：块级公式内可以用`\\`或者`\newline`实现换行，比如：
     $$
     a + b = c \\
     c - b = a \\
     c - a = b
     $$
  3. **对齐与编号**：默认块级公式居中显示，如果需要左对齐或者自定义对齐规则，可以使用`aligned`环境；Typora、Obsidian等编辑器支持开启公式自动编号，在公式末尾加`\label{标签名}`，正文可以用`\ref{标签名}`引用，比如：
     $$
     \int_a^b f(x) dx = F(b) - F(a) \label{newton-leibniz}
     $$
     正文中写`牛顿-莱布尼茨公式如\ref{newton-leibniz}所示`，渲染后会自动替换为公式编号。
