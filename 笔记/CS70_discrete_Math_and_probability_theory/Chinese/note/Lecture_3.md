# 1 数学归纳法（Mathematical Induction）

引言。本讲将介绍**数学归纳法（Mathematical Induction）**这一证明技巧。归纳法是一种用于证明某一命题对所有自然数成立的强大工具。自然数显然有无穷多个，而归纳法提供了一种通过有限步骤对无穷多情况进行推理的方法。

我们通过一个例子来阐释归纳法的核心思想。假设我们需要证明命题：对于所有自然数$n$，$0 + 1 + 2 + 3 + \cdots + n = \frac{n(n+1)}{2}$。使用第1讲课程讲义（Note 1）中的全称量词，我们可以将该命题更正式地写为：
$$\forall n \in \mathbb{N}, \sum_{i=0}^{n} i = \frac{n(n+1)}{2}. \tag{1}$$

如何证明这一命题？你或许会先验证它对$n=0,1,2$等情况成立，但我们需要验证无穷多个$n$的取值！此外，仅验证前几个$n$的取值不足以说明命题对所有$n \in \mathbb{N}$都成立，如下例所示：

**合理性检验！** 考虑命题：$\forall n \in \mathbb{N}$，$n^2 - n + 41$是质数。你可以验证前几个自然数都满足该命题（实际上，一直验证到$n=40$都不会找到反例！），但请试试$n=41$的情况。

在数学归纳法中，我们通过一个巧妙的观察来规避这个问题：假设命题对于某个$n=k$成立，即$\sum_{i=0}^{k} i = \frac{k(k+1)}{2}$（这一假设称为**归纳假设（Induction Hypothesis）**）。那么：
$$\left( \sum_{i=0}^{k} i \right) + (k + 1) = \frac{k(k + 1)}{2} + (k + 1) = \frac{(k + 1)(k + 2)}{2}, \tag{2}$$
即命题对于$n=k+1$也成立！换言之，如果命题对某个$k$成立，那么它必然对$k+1$也成立。我们将上述推导过程称为**归纳步骤（Inductive Step）**。归纳步骤是非常强大的工具：如果我们能证明命题对$k$成立，那么通过归纳步骤可以得出它对$k+1$成立；既然它对$k+1$成立，再次应用归纳步骤就能得到它对$k+2$成立，依此类推。实际上，我们可以无限重复这一推导，覆盖所有$n \geq k$的情况。那么这样就足够了吗？我们证明了等式(1)吗？还差一步！

问题在于，要应用归纳步骤，我们首先需要确定等式(1)对某个初始值$k$成立。由于我们的目标是证明命题对所有自然数成立，最自然的选择是$k=0$，我们将这个初始值的选择称为**基例（Base Case）**。如果基例成立，那么根据数学归纳法公理，通过归纳步骤即可推导出等式(1)对所有$n \in \mathbb{N}$成立。

现在我们将这一证明过程正式重写如下。

**定理3.1** $\forall n \in \mathbb{N}, \sum_{i=0}^{n} i = \frac{n(n + 1)}{2}$。

证明：我们对变量$n$进行归纳。
- **基例（$n=0$）**：此时$\sum_{i=0}^{0} i = 0 = \frac{0(0 + 1)}{2}$，因此基例成立。
- **归纳假设**：对于任意$n=k \geq 0$，假设$\sum_{i=0}^{k} i = \frac{k(k+1)}{2}$。换言之，归纳假设即“假设我们已经证明了命题对任意$n=k \geq 0$成立”。
- **归纳步骤**：证明命题对$n=(k+1)$成立，即证明$\sum_{i=0}^{k+1} i = \frac{(k+1)(k+2)}{2}$：
$$\sum_{i=0}^{k+1} i = \left( \sum_{i=0}^{k} i \right) + (k + 1) = \frac{k(k + 1)}{2} + (k + 1) = \frac{k(k + 1) + 2(k + 1)}{2} = \frac{(k + 1)(k + 2)}{2}, \tag{3}$$
其中第二个等式由归纳假设得出。根据数学归纳法原理，命题得证。

**合理性检验！** 归纳假设是如何帮助我们得到等式(3)中的第二个等号的？（提示：我们用它替换了$\sum_{i=0}^k i$，从而简化计算。）

**要点回顾**。到目前为止我们学到了什么？令$P(n)$表示命题$\sum_{i=0}^{n} i = \frac{n(n+1)}{2}$，我们的目标是证明$\forall n \in \mathbb{N}, P(n)$。归纳法原理说明，要证明这一结论只需三个简单步骤：
1. 基例：证明$P(0)$为真。
2. 归纳假设：对于任意$k \geq 0$，假设$P(k)$为真。
3. 归纳步骤：在归纳假设成立的前提下，证明$P(k+1)$为真。

我们可以用多米诺骨牌来直观理解这三个步骤的关系。将命题$P(i)$对应为编号为$0,1,2,\dots,n$的一列多米诺骨牌，$P(0)$对应第0张骨牌，$P(1)$对应第1张，依此类推。骨牌的排列规则是：如果第$k$张骨牌倒下，那么它会撞倒第$k+1$张。撞倒第$k$张骨牌对应证明了$P(k)$为真，归纳步骤则对应骨牌的这种排列规则，确保第$k$张倒下时第$k+1$张必然随之倒下。基例（$n=0$）撞倒了第0张骨牌，由此引发的连锁反应会撞倒所有骨牌！

最后需要说明如何选择合适的基例：在本例中我们选择$k=0$，但通常基例的选择需要根据待证明的命题来确定。


## 另一个归纳法证明示例
我们再做一个归纳法证明的练习。回顾第1讲课程讲义（Note 1）中的定义：对于整数$a$和$b$，若存在整数$q$使得$b=aq$，则称$a$整除$b$，记为$a \mid b$。

**定理3.2** 对所有$n \in \mathbb{N}$，$n^3 - n$能被3整除。

证明：我们对$n$进行归纳。令$P(n)$表示命题“$n^3 - n$能被3整除”。
- **基例（$n=0$）**：$P(0)$表示$3 \mid (0^3 - 0)$，即$3 \mid 0$，这显然成立，因为任意非零整数都整除0。
- **归纳假设**：对于$n=k \geq 0$，假设$P(k)$为真，即$3 \mid (k^3 - k)$，等价地，存在整数$q$使得$k^3 - k = 3q$。
- **归纳步骤**：证明$P(k+1)$为真，即$3 \mid ((k+1)^3 - (k+1))$。我们将$(k+1)^3 - (k+1)$展开如下：
$$
\begin{align*}
(k + 1)^3 - (k + 1) &= k^3 + 3k^2 + 3k + 1 - (k + 1) \\
&= (k^3 - k) + 3k^2 + 3k \\
&= 3q + 3(k^2 + k) \quad \text{（由归纳假设，$q \in \mathbb{Z}$）} \\
&= 3(q + k^2 + k).
\end{align*}
$$
由此可得$3 \mid ((k+1)^3 - (k+1))$。根据归纳法原理，$\forall n \in \mathbb{N}, 3 \mid (n^3 - n)$。

**合理性检验！** 归纳假设是如何帮助我们得到上述推导中的第三个等式的？

## 两色定理
接下来我们看一个更复杂的归纳法证明，它是著名的四色定理的简化版本。四色定理指出，任意地图都可以用四种颜色着色，使得任意两个相邻国家¹的颜色不同。四色定理的证明难度极高，自1852年该问题被首次提出以来，曾出现过多份错误的证明。实际上，直到1976年，阿佩尔（Appel）和哈肯（Haken）才借助计算机完成了该定理的证明。（若想了解该问题的有趣历史以及最新的证明（仍然极具挑战性），可访问www.math.gatech.edu/~thomas/FC/fourcolor.html。）

本讲中我们考虑该定理的一个简化版本：我们的“地图”是一个矩形，通过绘制直线将其划分为多个区域，每条直线都将矩形分为两个部分。这样的简化地图是否可以仅用两种颜色（例如红色和蓝色）着色，使得任意两个相邻区域的颜色不同？下图是一个两色着色的示例：

**定理3.3** 令$P(n)$表示命题“任意包含$n$条直线的上述形式的地图都可以用两种颜色着色”，则$\forall n \in \mathbb{N}, P(n)$成立。

证明：我们对$n$进行归纳。
- **基例（$n=0$）**：显然$P(0)$成立，因为如果地图中没有直线，我们可以用单一颜色为整个区域着色。
- **归纳假设**：对于任意$n=k \geq 0$，假设$P(k)$成立。
- **归纳步骤**：我们证明$P(k+1)$成立。具体来说，给定一个包含$k+1$条直线的地图，我们需要证明它可以被两色着色。考虑移除其中一条直线后的情况：此时地图中仅有$k$条直线，根据归纳假设，我们可以对其进行两色着色。我们可以观察到如下性质：对于任意合法的着色方案，如果将红色和蓝色互换，得到的仍然是一个合法的着色方案。基于这一性质，我们将移除的直线放回地图，保持该直线一侧的颜色不变，将另一侧的颜色全部红↔蓝互换。这一过程如图1所示。我们断言，这就是包含$k+1$条直线的地图的一个合法两色着色方案。


**图1**：(左) 移除第$k+1$条直线后的地图。(右) 第$k+1$条直线以虚线表示的地图。

为什么这一方法是有效的？考虑任意两个共享边界的区域，必然属于以下两种情况之一：
情况1：共享边界正是我们移除后放回的那条直线，即第$k+1$条直线。根据我们的构造，该直线一侧的颜色全部被翻转，因此被这条直线分隔的两个区域颜色必然不同。
情况2：共享边界是前$k$条直线中的某一条。此时根据归纳假设，被这条边界分隔的两个区域原本颜色就不同。而我们的颜色翻转操作要么同时改变这两个区域的颜色（如果它们都在被翻转的一侧），要么都不改变（如果都在未被翻转的一侧），因此它们的颜色仍然不同。

综上，两种情况下共享边界的区域颜色都不同，满足着色要求。

# 2 强化归纳假设
使用归纳法时，选择正确的待证明命题至关重要。例如，假设我们需要证明命题：对于所有$n \geq 1$，前$n$个奇数的和是完全平方数。下面是第一次归纳证明的尝试：

**证明尝试**：我们对$n$进行归纳。
- **基例（$n=1$）**：第一个奇数是1，是完全平方数，基例成立。
- **归纳假设**：假设前$k$个奇数的和是完全平方数，记为$m^2$。
- **归纳步骤**：第$k+1$个奇数是$2k+1$。因此根据归纳假设，前$k+1$个奇数的和为$m^2 + 2k + 1$。但此时我们的推导卡住了：为什么$m^2 + 2k + 1$一定是完全平方数？

看起来我们的归纳假设太“弱”了，它没有提供足够的结构来帮助我们推导$k+1$的情况。


我们不妨先退一步，做一个初步验证，确认我们的结论不是显然错误的：我们可以计算前几个情况的结果，或许在这个过程中能发现之前没有注意到的隐藏结构。
- $n=1$：$1 = 1^2$，是完全平方数。
- $n=2$：$1 + 3 = 4 = 2^2$，是完全平方数。
- $n=3$：$1 + 3 + 5 = 9 = 3^2$，是完全平方数。
- $n=4$：$1 + 3 + 5 + 7 = 16 = 4^2$，是完全平方数。

我们得到了好消息，甚至是更好的消息：好消息是我们还没有找到反例，更好的消息是其中出现了一个惊人的规律：前$n$个奇数的和不只是完全平方数，而且恰好等于$n^2$！受这一发现的启发，我们尝试一个看似反直觉的做法：我们来证明一个更强的命题。

**定理3.4** 对于所有$n \geq 1$，前$n$个奇数的和为$n^2$。

证明：我们对$n$进行归纳。
- **基例（$n=1$）**：第一个奇数是1，等于$1^2$，基例成立。
- **归纳假设**：假设前$k$个奇数的和为$k^2$。
- **归纳步骤**：第$k+1$个奇数是$2k+1$。应用归纳假设，前$k+1$个奇数的和为$k^2 + (2k + 1) = (k + 1)^2$。因此根据归纳法原理，定理成立。

我们来梳理一下这一过程：我们原本无法证明原始命题，因此转而假设了一个更强的命题，反而成功证明了它。为什么这一方法可行？原因在于原始命题没有捕捉到我们要证明的事实的底层结构，表述过于模糊，导致归纳假设不足以推导出我们想要的结果。相比之下，尽管第二个命题表面上更强，但它包含了更多结构，这反过来使得归纳假设也更强：我们不仅可以假设前$k$个奇数的和是完全平方数，还可以假设它恰好等于$k^2$。这一额外的结构正是我们完成证明所需要的。总而言之，我们通过这个例子看到：即使命题本身为真，归纳假设的精确表述也会直接决定证明的成败。

## 示例
我们再看第二个例子，这次需要你参与部分推导！假设我们需要证明命题：对于所有$n \geq 1$，$\sum_{i=1}^{n} \frac{1}{i^2} \leq 2$。

**合理性检验！** “显然”的归纳假设是：假设对于$n=k$，$\sum_{i=1}^{k} \frac{1}{i^2} \leq 2$。为什么这个假设不足以证明$n=k+1$的情况，即无法推出$\sum_{i=1}^{k} \frac{1}{i^2} + \frac{1}{(k+1)^2} \leq 2$？（提示：$\sum_{i=1}^{k} \frac{1}{i^2}$有没有可能恰好等于2？）


**定理3.5** 对于所有$n \geq 1$，$\sum_{i=1}^{n} \frac{1}{i^2} \leq 2 - \frac{1}{n}$。

证明：我们对$n$进行归纳。
- **基例（$n=1$）**：此时$\sum_{i=1}^{1} \frac{1}{i^2} = 1 \leq 2 - \frac{1}{1}$，满足要求。
- **归纳假设**：假设命题对$n=k$成立。
- **归纳步骤**：根据归纳假设，有：
$$\sum_{i=1}^{k+1} \frac{1}{i^2} = \sum_{i=1}^{k} \frac{1}{i^2} + \frac{1}{(k + 1)^2} \leq 2 - \frac{1}{k} + \frac{1}{(k + 1)^2}.$$
因此，要证明命题成立，只需证明：
$$- \frac{1}{k} + \frac{1}{(k + 1)^2} \leq - \frac{1}{k + 1}. \tag{4}$$

**练习**：证明不等式(4)成立。（提示：将不等式两边同时乘以$(k+1)$。）
根据数学归纳法（Mathematical Induction）原理，命题得证。

# 3 简单归纳与强归纳
到目前为止，我们使用的归纳法称为**简单归纳（Simple Induction）**或**弱归纳（Weak Induction）**。接下来我们介绍另一种归纳法，称为**强归纳（Strong Induction）**。它与简单归纳类似，区别仅在于归纳假设不同：强归纳不再仅假设$P(k)$为真（简单归纳的假设），而是假设更强的结论：$P(0), P(1), \dots, P(k)$全部为真（即$\bigwedge_{i=0}^{k} P(i)$为真）。

强归纳和弱归纳的证明能力有区别吗？也就是说，强归纳能证明的命题，弱归纳是不是无法证明？答案是否定的！我们可以通过之前的多米诺骨牌类比直观理解这一点：在多米诺骨牌的图景中，弱归纳表示如果第$k$张骨牌倒下，那么第$k+1$张也会倒下；而强归纳表示如果第1到第$k$张骨牌全部倒下，第$k+1$张才会倒下。但这两种场景是等价的：如果第一张骨牌倒下，反复应用弱归纳就可以得出第1张骨牌会依次撞倒第2到第$k$张，从而满足强归纳中第$k+1$张倒下的前提。尽管如此，强归纳仍然有明显的优势：它可以简化证明，因为我们可以假设更强的归纳假设。怎么理解这一点呢？可以类比螺丝刀和电动螺丝刀：两者都能完成同样的工作，但后者使用起来要方便得多！

我们来看一个简单的强归纳示例²，这也是我们第一个需要多个基例的归纳证明。
**定理3.6** 对于任意自然数$n \geq 12$，存在$x,y \in \mathbb{N}$使得$n = 4x + 5y$。
证明：我们对$n$进行归纳。
- **基例（$n=12$）**：$12 = 4 \cdot 3 + 5 \cdot 0$，满足条件。
- **基例（$n=13$）**：$13 = 4 \cdot 2 + 5 \cdot 1$，满足条件。
- **基例（$n=14$）**：$14 = 4 \cdot 1 + 5 \cdot 2$，满足条件。
- **基例（$n=15$）**：$15 = 4 \cdot 0 + 5 \cdot 3$，满足条件。
- **归纳假设**：对于$k \geq 15$，假设所有$12 \leq n \leq k$都满足该命题。
- **归纳步骤**：我们证明$n = k + 1 \geq 16$时命题成立。注意到$(k+1) - 4 \geq 12$，因此根据归纳假设，$(k+1) - 4 = 4x' + 5y'$，其中$x', y' \in \mathbb{N}$。令$x = x' + 1$，$y = y'$，即可得证。

**合理性检验！** 如果我们用弱归纳代替强归纳，上面的证明为什么会失效？

我们再看一个更复杂的示例。首先回顾素数的定义：若$n \geq 2$的正约数只有1和$n$本身，则称$n$为素数（质数）。
**定理3.7** 任意大于1的自然数$n$都可以表示为一个或多个素数的乘积。
证明：我们对$n$进行归纳。令$P(n)$表示命题“$n$可以表示为素数的乘积”，我们将证明对所有$n \geq 2$，$P(n)$为真。
- **基例（$n=2$）**：我们从$n=2$开始。显然$P(2)$成立，因为2本身就是素数。
- **归纳假设**：假设所有$2 \leq n \leq k$都满足$P(n)$为真。
- **归纳步骤**：证明$n = k + 1$可以表示为素数的乘积。分两种情况讨论：$k+1$是素数，或者不是素数。第一种情况，如果$k+1$是素数，那么命题显然成立，因为$k+1$本身就是单个素数的乘积（即它自己）。第二种情况，如果$k+1$不是素数，根据定义，存在正整数$x,y$满足$1 < x, y < k+1$，使得$k+1 = xy$。根据归纳假设，$x$和$y$都可以表示为素数的乘积（因为$x,y \leq k$），因此$k+1$也可以表示为素数的乘积。

**合理性检验！** 如果我们使用简单归纳，这个证明为什么会失效？（提示：假设$k=42$，因为$42 = 6 \times 7$，在归纳步骤中我们需要用到$P(6)$和$P(7)$为真的结论。但弱归纳无法提供这一结论——弱归纳在该情况下仅允许我们假设哪个$P(n)$为真？）
² 这个问题也被称为**邮票问题（Postage Stamp Problem）**，即任何不低于12美分的邮资都可以仅用4美分和5美分的邮票组合支付。

---

最后，如果你希望更正式地理解弱归纳和强归纳的等价性，可以考虑如下构造：令$Q(n) = P(0) \land P(1) \land \cdots \land P(n)$，那么对$P$进行强归纳等价于对$Q$进行弱归纳。你可以自行验证这一结论。

# 4 递归、编程与归纳
归纳和递归之间存在紧密的联系，我们通过两个示例来探究这一点。
## 示例1：斐波那契的兔子
13世纪有一位著名的意大利数学家斐波那契³，他在1202年提出了如下谜题：从一对兔子开始，假设每对兔子每个月都会生下一对新兔子，且新生的兔子从第二个月开始具备繁殖能力，那么一年后总共有多少对兔子？这种种群增长模型可以通过递归定义函数来建模，得到的数列就是如今广为人知的斐波那契数列（Fibonacci Sequence）。

我们用$F(n)$表示第$n$个月的兔子对数，通过上述规则来递归建模兔子种群。首先给出初始条件：显然$F(0) = 0$；第1个月引入一对兔子，因此$F(1) = 1$；此外，由于新生兔子需要一个月才能具备繁殖能力，因此$F(2) = 1$。

第3个月开始情况变得有趣：例如$F(3) = 2$，因为最初的一对兔子繁殖出了一对新兔子。但对于一般的$n$，$F(n)$如何计算？直接给出$F(n)$的显式表达式似乎很难，但我们可以递归地定义$F(n)$：第$n-1$个月时，根据定义有$F(n-1)$对兔子。其中有多少对具备繁殖能力？只有那些在上一个月就已经存在的兔子，即$F(n-2)$对。因此第$n$个月会新增$F(n-2)$对兔子，加上已有的$F(n-1)$对，可得$F(n) = F(n-1) + F(n-2)$。总结如下：
- $F(0) = 0$。
- $F(1) = 1$。
- 对于$n \geq 2$，$F(n) = F(n-1) + F(n-2)$。

这个模型很有意思，但你可能会疑惑我们为什么要关心兔子的繁殖问题？实际上，这个简化的种群增长模型阐释了一个基本原理：如果不受限制，种群数量会随时间指数增长。下面的练习给出了这种指数增长速率的一个下界（真实的增长速率更高，约为$1.6^n$）。
**练习**：使用归纳法证明斐波那契数满足：对于所有$n \geq 3$，$F(n) \geq 2^{(n-1)/2}$。注意你需要两个基例：$n=3$和$n=4$。（为什么？）

实际上，理解这种不受限制的指数种群增长的重要性，是达尔文提出进化论的关键一步。引用达尔文的原话：“所有生物都以如此高的速率增长，这是没有例外的规律：如果不被毁灭，地球很快就会被一对生物的后代所覆盖。”
³ 斐波那契也被称为比萨的列奥纳多。如果你有机会去意大利比萨，可以去参观他的墓地，他的遗骸安葬在 Camposanto（比萨墓园）。

我们在本节标题中提到了编程，现在就来实现它——下面是一个计算$F(n)$的简单递归程序：
```
function F(n)
if n=0 then return 0
if n=1 then return 1
else return F(n-1) + F(n-2)
```
**练习**：这个程序计算$F(n)$需要多长时间？也就是说，总共需要调用多少次$F(n)$？你可以通过归纳法证明，调用次数至少为$F(n)$本身！

上面的练习会让你意识到，这是计算第$n$个斐波那契数的极低效方式。下面是一个快得多的迭代算法来完成同样的任务（这是将尾递归转换为迭代算法的常见示例）：
```
function F2(n)
if n=0 then return 0
if n=1 then return 1
a = 1
b = 0
for k = 2 to n do
temp = a
a = a + b
b = temp
return a
```
**练习**：这个迭代算法计算$F2(n)$需要多长时间？也就是循环需要执行多少次？你可以通过归纳法证明这个新函数$F2(n) = F(n)$吗？

## 示例2：二分查找
接下来我们用归纳法分析一个即使是长辈都很熟悉的递归算法——二分查找（Binary Search）！我们以在字典中查找单词为例来讨论二分查找：要查找单词$W$，我们先翻到字典的中间页。如果该页的第一个单词比$W$靠后，我们就递归查找字典的前半部分（中间页之前的部分）；否则递归查找后半部分（从中间页开始的部分）。（当字典有偶数$2m$页时，我们定义中间页为第$m+1$页。）当我们把查找范围缩小到只有一页时，就用暴力搜索在该页查找$W$。伪代码如下：

---

```
1. // 前置条件：W 是待查找单词，D 是字典的子集，至少包含1页。
2. // 后置条件：如果 W 在字典中，返回其释义；否则返回“未找到 W”。
3. findWord(W , D) {
4. // 基例
5. If (D 恰好只有1页)
6.     暴力搜索D中的W。如果找到，返回其释义；否则返回“未找到 W”。
7.
8. // 递归情况
9. Let W' 是D的中间页的第一个单词。
10. If ( W 在 W' 之前 )
11.    return findWord( D 的前半部分 )
12. Else
13.    return findWord( D 的后半部分 )
14. }
```
我们用归纳法证明`findWord()`的正确性，即如果$W$在字典$D$中，函数会返回它的释义。额外的好处是，这个证明需要使用强归纳而非简单归纳！

**findWord() 正确性证明**：我们对$D$的页数$n$进行强归纳。
- **基例（$n=1$）**：如果$D$只有1页，第6行会暴力搜索$W$。因此如果$W$存在，就会被找到并返回；否则返回“未找到$W$”，符合要求。
- **归纳假设**：假设对于所有$1 \leq n \leq k$，`findWord()`都能正确执行。
- **归纳步骤**：我们证明$n = k + 1$时`findWord()`正确。执行第9步后我们得到$W'$，因此可以判断$W$应该在$D$的前半部分还是后半部分。如果是前半部分，我们在第11行递归查找$D$的前半部分；如果是后半部分，在第13行递归查找$D$的后半部分。根据归纳假设，递归调用会正确地在前半部分或后半部分找到$W$，或者返回“未找到$W$”，因为这两部分的页数都不超过$k$。由于我们返回的是递归调用的结果，因此可以得出`findWord()`对于大小为$n = k + 1$的$D$能正确查找$W$。根据归纳法，`findWord()`是正确的。

**合理性检验！** 为什么上面的证明需要用强归纳？

# 5 错误证明
如果证明过程不正确，很容易得出错误的结论！我们用一个著名的例子来说明这一点。上世纪中期有一句常用的口语“那是一匹不同颜色的马”，用来指代和常规预期差异很大的事物。著名数学家乔治·波利亚（George Pólya）同时也是面向大众的优秀数学科普作家，他给出了如下证明，说明“不存在不同颜色的马”！

**定理3.8** 所有马的颜色都相同。
证明：我们对马的数量$n$进行归纳。令$P(n)$表示该命题。
- **基例（$n=1$）**：$P(1)$显然为真，因为如果一个集合里只有一匹马，集合里所有马的颜色当然相同。
- **归纳假设**：假设对于任意$n \geq 1$，$P(n)$成立。
- **归纳步骤**：给定一个包含$n+1$匹马的集合$\{h_1, h_2, \dots, h_{n+1}\}$，我们可以排除最后一匹马，对前$n$匹马$\{h_1, \dots, h_n\}$应用归纳假设，得出它们的颜色都相同。类似地，我们可以得出后$n$匹马$\{h_2, \dots, h_{n+1}\}$的颜色都相同。而“中间”的马$\{h_2, \dots, h_n\}$（即除了第一匹和最后一匹之外的马）同时属于这两个集合，因此它们的颜色和$h_1$、$h_{n+1}$都相同。由此可得，所有$n+1$匹马的颜色都相同。根据数学归纳法原理，所有马的颜色都相同。

显然，并不是所有马的颜色都相同！那么我们哪里出错了？回顾数学归纳法的应用要求，归纳步骤必须证明：$\forall n \geq 1, P(n) \implies P(n+1)$。我们断言，上述证明中这个蕴含式是假的——特别地，存在某个$n$的取值是这个蕴含式的反例。

**练习**：对于哪个$n$的取值，$P(n) \implies P(n+1)$不成立？（提示：思考证明中“存在中间的马”这一关键性质什么时候成立。）

# 6 练习题

2. 在实分析中，**伯努利不等式（Bernoulli's Inequality）**是对$1+x$的幂运算的近似不等式。证明该不等式：若$n$为自然数，且$1+x>0$，则$(1+x)^n \geq 1 + nx$。
3. 阶乘是一个常见的递归定义函数，对于非负整数$n$，$n! = n(n-1)(n-2)\cdots 1$，基例为$0! = 1$。我们通过如下关于阶乘的定理来进一步理解递归和归纳的联系。
> **定理**：对所有$n \in \mathbb{N}$，$n > 1 \implies n! < n^n$。
用归纳法证明该定理。（提示：在归纳步骤中，将$(n+1)!$写为$(n+1) \cdot n!$，并使用归纳假设。）
4. 派对上的名人指的是所有人都认识他，但他不认识任何人的人。假设你在一个有$n$个人的派对上，对于任意两个人A和B，你可以询问A是否认识B，并得到诚实的回答。设计一个递归算法，通过最多$3n-4$次询问，判断派对上是否有名人，如果有则找出这个人。（注：本题中你只是派对的访客，负责提问，你需要判断的是实际参加派对的$n$个人中是否包含名人。）
通过归纳法证明你的算法总能在有名人时正确识别出名人，且询问次数不超过$3n-4$。
