## 一、文件权限问题详解

### 1. 错误信息：`E212: Can't open file for writing: permission denied`

### 2. 常见原因
- **文件属于 root 或其他用户**（常见于系统文件）
- **文件是只读的**（使用 `chmod` 设置了只读权限）
- **当前目录没有写权限**
- **文件系统被挂载为只读**

### 3. 解决方案

#### 3.1 检查权限
```bash
# 查看文件权限
ls -l 文件名

# 查看目录权限
ls -ld 目录名

# 示例输出分析
# -rw-r--r-- 1 root root 4096 Jan 1 12:00 filename
# ↑ 这里显示所有者是 root，普通用户不能修改
```

#### 3.2 使用 sudo 保存（推荐）
在 **Neovim 内部**执行：
```
# 按 Esc 进入命令模式，然后输入：
:w !sudo tee %

# 或者更安全的方式：
:w !sudo tee > /dev/null %
```
然后输入密码确认覆盖。

#### 3.3 更改文件权限
```bash
# 退出 Neovim（:q!），在终端执行：
sudo chmod +w 文件名     # 添加写权限
# 或
sudo chown $USER 文件名  # 将文件所有者改为当前用户
```

#### 3.4 保存到临时位置再移动
在 Neovim 中：
```
# 按 Esc 进入命令模式
:w /tmp/临时文件名       # 保存到 /tmp 目录
```
然后在终端：
```bash
sudo mv /tmp/临时文件名 /原路径/
```

#### 3.5 从一开始就用 sudo 打开
```bash
# 退出当前 Neovim (:q!)
sudo nvim 文件名
```

### 4. 预防措施
1. **编辑系统文件时**总是用 `sudo nvim`
2. **普通用户文件**不需要特殊权限
3. 使用 `ls -l` 提前检查权限

## 二、创建临时文件进行命令练习

### 1. 推荐创建位置（都有写权限）
- **家目录（最安全）**：`cd ~`
- **/tmp 目录（临时，重启会消失）**：`cd /tmp`

### 2. 创建练习目录
```bash
# 在家目录创建专用目录
mkdir ~/linux_practice
cd ~/linux_practice
```

### 3. 创建临时文件的几种方法

#### 3.1 使用 cat 直接创建（推荐）
```bash
cat > fruits.txt << 'EOF'
apple
orange
banana
apple
grape
orange
banana
mango
EOF
```

#### 3.2 使用 echo 逐行添加
```bash
touch test.txt
echo "apple" >> test.txt
echo "orange" >> test.txt
echo "banana" >> test.txt
```

#### 3.3 使用 mktemp（标准临时文件）
```bash
TEMP_FILE=$(mktemp)
cat > $TEMP_FILE << 'EOF'
apple
orange
banana
apple
grape
orange
banana
EOF
```

## 三、常用命令练习

### 1. cat 命令
```bash
# 查看文件内容
cat practice.txt

# 查看文件内容并显示行号
cat -n practice.txt

# 查看文件内容并显示非打印字符
cat -A practice.txt

# 合并多个文件
cat file1.txt file2.txt > combined.txt
```

### 2. sort 命令
```bash
# 按字母顺序排序
sort practice.txt

# 按字母顺序逆序排序
sort -r practice.txt

# 按数字排序
sort -n numbers.txt

# 排序并去重
sort -u practice.txt
```

### 3. uniq 命令
```bash
# 注意：uniq 需要输入已排序！
# 先排序，然后去重
sort practice.txt | uniq

# 只显示重复的行
sort practice.txt | uniq -d

# 显示每行出现的次数
sort practice.txt | uniq -c

# 显示所有不重复的行
sort practice.txt | uniq -u
```

### 4. 组合练习

#### 4.1 统计出现次数
```bash
sort practice.txt | uniq -c | sort -rn
# 输出示例：
#    3 apple
#    2 orange
#    2 banana
#    1 zebra
#    1 mango
#    1 grape
```

#### 4.2 找出重复项
```bash
sort practice.txt | uniq -d
# 输出：
# apple
# banana
# orange
```

#### 4.3 创建去重后的新文件
```bash
sort practice.txt | uniq > unique_fruits.txt
cat unique_fruits.txt
```

## 四、常见错误场景与解决

### 场景1：在根目录创建文件被拒绝
```bash
# 错误操作
cd /
data > the_data.text  # Permission denied

# 正确做法
cd ~  # 切换到有权限的目录
data > the_data.text
```

### 场景2：编辑系统文件无法保存
```bash
# 错误操作
nvim /etc/hosts  # 编辑后无法保存

# 正确做法
sudo nvim /etc/hosts  # 一开始就用 root 权限
```

### 场景3：目录无写权限
```bash
# 检查当前目录权限
pwd
ls -ld .

# 切换到家目录
cd ~
# 或使用 /tmp 目录
cd /tmp
```

## 五、实用技巧总结

### 1. 权限检查三步曲
```bash
# 第一步：查看当前位置
pwd

# 第二步：检查权限
ls -ld .

# 第三步：查看用户身份
whoami
```

### 2. 安全练习环境设置
```bash
# 创建专用练习目录
mkdir -p ~/linux_practice/{cat,sort,uniq}
cd ~/linux_practice/cat

# 创建示例文件
cat > sample.txt << 'EOF'
练习数据
多行文本
用于命令测试
EOF
```

### 3. 常用命令速查表
| 命令    | 功能         | 常用选项                            |
| ------- | ------------ | ----------------------------------- |
| `cat`   | 查看文件内容 | `-n` 显示行号，`-A` 显示所有字符    |
| `sort`  | 排序文件内容 | `-r` 逆序，`-n` 数字排序，`-u` 去重 |
| `uniq`  | 去除重复行   | `-c` 计数，`-d` 只显示重复行        |
| `ls`    | 列出文件信息 | `-l` 详细信息，`-a` 包括隐藏文件    |
| `chmod` | 修改权限     | `+w` 添加写权限                     |
| `chown` | 修改所有者   | `$USER` 当前用户                    |

### 4. 常见问题快速诊断
1. **Permission denied** → 检查当前目录权限，切换到家目录
2. **Command not found** → 检查命令拼写，使用 `which 命令名`
3. **无法保存文件** → 使用 `:w !sudo tee %` 或 `sudo nvim`
4. **文件乱码** → 检查编码，使用 `file -i 文件名`

## 六、实践练习建议

### 1. 按顺序练习
```bash
# 第一步：创建测试文件
cd ~
cat > animals.txt << 'EOF'
cat
dog
bird
cat
fish
dog
elephant
bird
EOF

# 第二步：使用 cat 查看
cat animals.txt

# 第三步：使用 sort 排序
sort animals.txt

# 第四步：使用 uniq 去重
sort animals.txt | uniq

# 第五步：组合练习
sort animals.txt | uniq -c | sort -rn
```

### 2. 清理练习文件
```bash
# 删除单个文件
rm practice.txt

# 删除整个目录
rm -rf ~/linux_practice

# 清空屏幕
clear  # 或 Ctrl+L
```

### 3. 扩展练习
```bash
# 创建复杂数据文件
cat > students.txt << 'EOF'
Alice 95
Bob 87
Charlie 92
Alice 95
David 78
Bob 87
Eve 91
EOF

# 练习：找出分数重复的学生记录
sort students.txt | uniq -d
```

**注意事项**：
1. 练习时尽量在家目录操作，避免权限问题
2. 编辑系统文件时格外小心，最好先备份
3. 使用 Tab 键补全文件名和命令
4. 善用 `man` 命令查看帮助（如 `man cat`）
