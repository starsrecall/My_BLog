# 简单介绍

1. Mermaid 是一个基于 JavaScript 的图表绘制工具，它使用类似 Markdown 的纯文本语法来描述图表，并能在浏览器中动态渲染成 SVG 或图片。
2. Mermaid 诞生于 2014 年，由 Knut Sveidqvist 创建。





------



# 它能做什么

Mermaid 支持多种图表类型，最常用的包括：

- **流程图**（Flowchart）
- **时序图**（Sequence Diagram）
- **甘特图**（Gantt Chart）
- **类图**（Class Diagram）
- **状态图**（State Diagram）
- **饼图**（Pie Chart）
- **用户旅程图**（User Journey）
- **Git 分支图**（Git Graph）
- ······

## 编辑器

- [**Mermaid Live Editor**](https://mermaid.live/)
- **[StackEdit](https://stackedit.io/)**
  浏览器端 Markdown 编辑器，内置 Mermaid 支持。
- **[HackMD / CodiMD](https://hackmd.io/)**
  协作式 Markdown 笔记，实时渲染 Mermaid 图表。
- **[Typora](https://typora.io/)**
  跨平台 Markdown 编辑器，原生支持 Mermaid（记得在设置中启用），我最喜欢的markdown编辑器，就是多端互通麻烦。
- **[Obsidian](https://obsidian.md/)**
  支持多端互通。
