# 装箱问题

**链接**
* [2015样题0-L1-7 装箱问题](https://pintia.cn/problem-sets/994805046380707840/problems/994805106325700608)

## 题目

假设有 N 项物品，大小分别为 s₁、s₂、...、sᵢ、...、sN，其中 sᵢ 为满足 1 ≤ sᵢ ≤ 100 的整数。要把这些物品装入到容量为 100 的一批箱子（序号 1-N）中。装箱方法是：对每项物品，顺序扫描箱子，把该物品放入足以能够容下它的第一个箱子中。请写一个程序模拟这种装箱过程，并输出每个物品所在的箱子序号，以及放置全部物品所需的箱子数目。

**输入格式：**
输入第一行给出物品个数 N（≤1000）；第二行给出 N 个正整数 sᵢ（1 ≤ sᵢ ≤ 100，表示第 i 项物品的大小）。

**输出格式：**
按照输入顺序输出每个物品的大小及其所在的箱子序号，每个物品占 1 行，最后一行输出所需的箱子数目。

**输入样例：**
```
8
60 70 80 90 30 40 10 20
```

**输出样例：**
```
60 1
70 2
80 3
90 4
30 1
40 5
10 1
20 2
5
```

## 方法

### 一：基础模拟法（最先适应算法）

**思路和算法**

最先适应算法（First Fit, FF）是题目要求的基本算法。对于每个物品，顺序扫描所有已有箱子，将其放入第一个剩余容量足够容纳该物品的箱子中。如果没有合适的箱子，则创建一个新箱子。

算法维护一个数组记录每个箱子的剩余容量，对每个物品执行以下操作：
1. 顺序扫描所有已有箱子
2. 找到第一个剩余容量 ≥ 当前物品大小的箱子
3. 将物品放入该箱子，更新箱子剩余容量
4. 如果没有找到合适箱子，创建新箱子

**代码**

```cpp
#include <iostream>
#include <vector>
using namespace std;

int main() {
    int n;
    cin >> n;
  
    vector<int> items(n);
    for (int i = 0; i < n; i++) {
        cin >> items[i];
    }
  
    // 模拟最先适应算法
    vector<int> box_remain;    // 箱子剩余容量
    vector<int> result(n);     // 物品的箱子序号
  
    for (int i = 0; i < n; i++) {
        int item = items[i];
        bool placed = false;
      
        // 顺序扫描已有箱子
        for (int j = 0; j < box_remain.size(); j++) {
            if (box_remain[j] >= item) {
                box_remain[j] -= item;
                result[i] = j + 1;  // 箱子序号从1开始
                placed = true;
                break;
            }
        }
      
        // 没有合适箱子，开新箱
        if (!placed) {
            box_remain.push_back(100 - item);
            result[i] = box_remain.size();
        }
    }
  
    // 输出结果
    for (int i = 0; i < n; i++) {
        cout << items[i] << " " << result[i] << endl;
    }
    cout << box_remain.size() << endl;
  
    return 0;
}
```

**复杂度分析**

- 时间复杂度：O(N²)，其中 N 为物品数量。每个物品最多需要扫描所有已有箱子，最坏情况下箱子数与物品数相同。
- 空间复杂度：O(N)，用于存储箱子剩余容量和物品的箱子序号。

### 二：线段树优化查找

**思路和算法**

基础模拟法中，查找第一个能容纳物品的箱子需要顺序扫描，时间复杂度为 O(N)。使用线段树可以加速这一查找过程，将每次查找的时间复杂度降为 O(log N)。

线段树的每个节点维护区间内箱子的最大剩余容量。查找时：
1. 从根节点开始
2. 如果左子树的最大剩余
3. 容量 ≥ 当前物品大小，优先查找左子树
4. 否则查找右子树
5. 递归进行直到找到叶子节点对应的箱子

**代码**

```cpp
#include <iostream>
#include <vector>
using namespace std;

class SegmentTree {
private:
    vector<int> max_capacity;  // 线段树节点，存储区间最大剩余容量
    int n;  // 箱子数量
  
    // 更新节点
    void update(int idx, int l, int r, int pos, int value) {
        if (l == r) {
            max_capacity[idx] = value;
            return;
        }
        int mid = (l + r) / 2;
        if (pos <= mid) {
            update(idx * 2, l, mid, pos, value);
        } else {
            update(idx * 2 + 1, mid + 1, r, pos, value);
        }
        max_capacity[idx] = max(max_capacity[idx * 2], max_capacity[idx * 2 + 1]);
    }
  
    // 查询第一个剩余容量 ≥ target 的箱子索引
    int query(int idx, int l, int r, int target) {
        if (max_capacity[idx] < target) {
            return -1;  // 没有符合条件的箱子
        }
        if (l == r) {
            return l;  // 找到箱子索引
        }
        int mid = (l + r) / 2;
        // 优先查找左子树
        if (max_capacity[idx * 2] >= target) {
            return query(idx * 2, l, mid, target);
        } else {
            return query(idx * 2 + 1, mid + 1, r, target);
        }
    }

public:
    SegmentTree(int max_boxes) {
        n = max_boxes;
        max_capacity.resize(4 * n, 0);
    }
  
    // 插入新箱子
    void insertBox(int box_id, int capacity) {
        update(1, 0, n - 1, box_id, capacity);
    }
  
    // 查找第一个能容纳 item 的箱子
    int findFirstFit(int item) {
        return query(1, 0, n - 1, item);
    }
  
    // 更新箱子剩余容量
    void updateCapacity(int box_id, int new_capacity) {
        update(1, 0, n - 1, box_id, new_capacity);
    }
};

int main() {
    int n;
    cin >> n;
  
    vector<int> items(n);
    for (int i = 0; i < n; i++) {
        cin >> items[i];
    }
  
    SegmentTree segTree(n);  // 最多需要n个箱子
    vector<int> result(n);
    int box_count = 0;
  
    for (int i = 0; i < n; i++) {
        int item = items[i];
        int box_id = segTree.findFirstFit(item);
      
        if (box_id != -1) {
            // 从线段树中获取当前箱子的剩余容量（需要额外存储）
            // 实际实现中需要配合数组存储每个箱子的实际剩余容量
            int new_capacity = /* 当前容量 */ - item;
            segTree.updateCapacity(box_id, new_capacity);
            result[i] = box_id + 1;
        } else {
            // 创建新箱子
            segTree.insertBox(box_count, 100 - item);
            result[i] = box_count + 1;
            box_count++;
        }
    }
  
    // 输出结果（简化版，实际需要配合数组存储）
    for (int i = 0; i < n; i++) {
        cout << items[i] << " " << result[i] << endl;
    }
    cout << box_count << endl;
  
    return 0;
}
```

**复杂度分析**

- 时间复杂度：O(N log N)，每次查找和更新操作的时间复杂度为 O(log N)，共执行 N 次。
- 空间复杂度：O(N)，线段树需要 O(4N) 的空间，以及存储箱子状态的空间。

### 三：首次适应递减算法（离线优化）

**思路和算法**

首次适应递减算法（First Fit Decreasing, FFD）是一种离线算法，通过对物品按大小降序排序后再应用最先适应策略，可以显著提高箱子利用率。

FFD 算法的理论基础是：先处理大物品可以减少空间碎片，使得小物品更容易找到合适的箱子放置。该算法在理论上有较好的近似比，即使用箱子数不会超过最优解的 11/9（约 1.222 倍）。

**算法步骤：**
1. 将所有物品按大小降序排序
2. 按照排序后的顺序，对每个物品应用最先适应算法
3. 输出时按照原始顺序恢复物品的箱子序号

**代码**

```cpp
#include <iostream>
#include <vector>
#include <algorithm>
using namespace std;

int main() {
    int n;
    cin >> n;
  
    vector<int> items(n);
    vector<pair<int, int>> sorted_items;  // (大小, 原始索引)
  
    for (int i = 0; i < n; i++) {
        cin >> items[i];
        sorted_items.push_back({items[i], i});
    }
  
    // 按物品大小降序排序
    sort(sorted_items.begin(), sorted_items.end(), 
         [](const pair<int, int>& a, const pair<int, int>& b) {
             return a.first > b.first;
         });
  
    // 应用最先适应算法
    vector<int> box_remain;
    vector<int> result(n);
  
    for (auto& [size, idx] : sorted_items) {
        bool placed = false;
      
        for (int j = 0; j < box_remain.size(); j++) {
            if (box_remain[j] >= size) {
                box_remain[j] -= size;
                result[idx] = j + 1;
                placed = true;
                break;
            }
        }
      
        if (!placed) {
            box_remain.push_back(100 - size);
            result[idx] = box_remain.size();
        }
    }
  
    // 输出结果（按原始顺序）
    for (int i = 0; i < n; i++) {
        cout << items[i] << " " << result[i] << endl;
    }
    cout << box_remain.size() << endl;
  
    return 0;
}
```

**复杂度分析**

- 时间复杂度：O(N log N + N²)，其中 N log N 是排序的时间复杂度，N² 是最先适应算法的时间复杂度。对于 N ≤ 1000 的数据规模完全可行。
- 空间复杂度：O(N)，用于存储排序后的物品序列和箱子状态。

### 四：其他算法概述

#### 下次适应算法（Next Fit, NF）
- **规则**：只检查当前箱子，如果不满足则开新箱，并将新箱作为当前箱
- **特点**：实现简单，内存占用少，不回头扫描
- **近似比**：2.0
- **时间复杂度**：O(N)

#### 最佳适应算法（Best Fit, BF）
- **规则**：选择剩余容量最小但能容纳物品的箱子
- **特点**：箱子利用率较高，减少空间碎片
- **近似比**：1.7
- **时间复杂度**：O(N log N)（使用平衡树实现）

#### 最差适应算法（Worst Fit, WF）
- **规则**：选择剩余容量最大的箱子
- **特点**：保持箱子剩余容量相对均匀
- **近似比**：2.0
- **时间复杂度**：O(N log N)（使用最大堆实现）

#### 分桶优化
- **思路**：由于物品大小范围有限（1-100），按剩余容量分桶管理
- **实现**：创建大小为101的数组，buckets[r]存储剩余容量为r的箱子列表
- **查找**：从item到100查找第一个非空的桶
- **时间复杂度**：O(N × 100)，100为常数

### 算法性能比较

| 算法                       | 类型 | 时间复杂度         | 空间复杂度 | 近似比 | 适用场景           |
| -------------------------- | ---- | ------------------ | ---------- | ------ | ------------------ |
| First Fit (FF)             | 在线 | O(N²) / O(N log N) | O(N)       | 1.7    | 题目要求，实现简单 |
| Next Fit (NF)              | 在线 | O(N)               | O(1)       | 2.0    | 内存受限环境       |
| Best Fit (BF)              | 在线 | O(N log N)         | O(N)       | 1.7    | 要求箱子数少       |
| Worst Fit (WF)             | 在线 | O(N log N)         | O(N)       | 2.0    | 保持箱子均匀       |
| First Fit Decreasing (FFD) | 离线 | O(N log N + N²)    | O(N)       | 11/9   | 允许预知全部物品   |

**近似比说明**：算法解与最优解比值的最坏情况上界。例如近似比1.7表示算法最多使用最优解的1.7倍箱子。

### 总结

装箱问题虽然题目描述简单，但涉及丰富的算法思想和优化策略：

1. **基础模拟法**满足题目要求，实现简单直接
2. **线段树优化**展示了数据结构如何加速查找过程
3. **FFD算法**体现了离线处理对优化结果的重要影响
4. **不同适应策略**反映了贪心算法的多样性

在实际应用中，应根据具体场景选择合适的算法：
- 小规模数据：基础模拟法足够
- 中等规模：考虑线段树或平衡树优化
- 允许离线处理：优先使用FFD算法
- 内存受限：考虑NF算法

掌握这些算法不仅能解决装箱问题本身，更能提升解决其他资源分配和优化问题的能力。
