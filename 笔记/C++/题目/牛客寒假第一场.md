# L. Need Zero

**链接**
* 暂无在线评测链接，来源于2026牛客寒假集训营第一场

## 题目

给定正整数 \( n \)，要选一个正整数 \( x \) 使得 \( n + x \) 的末尾是 \( 0 \)，问 \( x \) 的最小值。

**输入格式：** 输入一个正整数 \( n \)。
**输出格式：** 输出最小的 \( x \)。

## 方法

### 方法一：分类讨论法

**思路和算法**

要使 \( n + x \) 的末尾为 \( 0 \)，即 \( n + x \) 是 \( 10 \) 的倍数。等价于 \( x \equiv -n \pmod{10} \)。由于 \( x \) 为正整数，最小满足条件的 \( x \) 为 \( (10 - n \% 10) \% 10 \)，但当 \( n \% 10 = 0 \) 时该值为 \( 0 \)，不符合正整数要求，此时最小应为 \( 10 \)。因此直接分类讨论即可。

**代码**

```cpp
#include <iostream>
using namespace std;

void solve() {
    int n;
    cin >> n;
    if (n % 10 == 0) {
        cout << 10 << endl;
    } else {
        cout << 10 - n % 10 << endl;
    }
}

int main() {
    solve();
    return 0;
}
```

**复杂度分析**
- 时间复杂度：\( O(1) \)
- 空间复杂度：\( O(1) \)

# K. Constructive

**链接**
* 暂无在线评测链接，来源于2026牛客寒假集训营第一场

## 题目

给定一个正整数 \( n \)，构造一个长度为 \( n \) 的数组 \( a \)，满足：
1. 每个元素都是正整数
2. 所有元素互不相同
3. 所有元素的乘积等于所有元素的和

如果存在，输出字典序最小的解；否则报告无解。

## 方法

### 方法一：小范围枚举

**思路和算法**

通过观察发现，只有当 \( n = 1 \) 或 \( n = 3 \) 时存在解：
- \( n = 1 \)：数组为 \([1]\)，乘积=和=1
- \( n = 3 \)：数组为 \([1, 2, 3]\)，乘积=和=6

对于其他 \( n \)，由于所有数字互不相同且为正整数，最小字典序数组为 \([1, 2, 3, \dots, n]\)，其乘积增长远快于和，因此无解。

**代码**

```cpp
#include <iostream>
using namespace std;

void solve() {
    int n;
    cin >> n;
    if (n == 1) {
        cout << "YES\n1\n";
    } else if (n == 3) {
        cout << "YES\n1 2 3\n";
    } else {
        cout << "NO\n";
    }
}

int main() {
    solve();
    return 0;
}
```

**复杂度分析**
- 时间复杂度：\( O(1) \)
- 空间复杂度：\( O(1) \)

# C. Array Covering

**链接**
* 暂无在线评测链接，来源于2026牛客寒假集训营第一场

## 题目

给定长度为 \( n \) 的数组 \( a \)，可以执行任意次操作：选择一对下标 \( (l, r) \)，将开区间 \( (l, r) \) 内的所有数变为区间端点值的较大者。求数组所有数字总和的最大值。

## 方法

### 方法一：贪心法

**思路和算法**

通过观察发现，总可以通过最多两次操作，将除了首尾元素外的所有元素都变为数组的最大值 \( mx \)：
1. 选择 \( (1, p) \) 其中 \( p \) 是最大值位置，将 \( (1, p) \) 区间内元素变为 \( mx \)
2. 选择 \( (p, n) \) 将 \( (p, n) \) 区间内元素变为 \( mx \)

最终总和为 \( mx \times (n-2) + a[1] + a[n] \)。

**代码**

```cpp
#include <iostream>
#include <vector>
#include <algorithm>
using namespace std;

void solve() {
    int n;
    cin >> n;
    vector<int> a(n + 1);
    int mx = 0;
    for (int i = 1; i <= n; i++) {
        cin >> a[i];
        mx = max(mx, a[i]);
    }
    cout << mx * (n - 2) + a[1] + a[n] << endl;
}

int main() {
    solve();
    return 0;
}
```

**复杂度分析**
- 时间复杂度：\( O(n) \)
- 空间复杂度：\( O(n) \)

# E. Block Game

## 题目

有 \( n \) 个小方块排成一排，第 \( i \) 个方块数字为 \( a_i \)，还有一个万能方块数字为 \( k \)。可以任意次将万能方块从最左侧插入，其余方块后移，最后一个方块变成新的万能方块。最大化第一个方块上的数字加上最终的万能方块上的数字。

## 方法

### 方法一：环状数组求最大相邻和

**思路和算法**

操作等价于将序列循环右移。将万能方块插入后形成长度为 \( n+1 \) 的循环序列，问题转化为在环状数组中找到相邻两数之和的最大值。

**代码**

```cpp
#include <iostream>
#include <vector>
#include <algorithm>
using namespace std;

void solve() {
    int n, k;
    cin >> n >> k;
    vector<int> a(n + 1);
    a[0] = k;
    for (int i = 1; i <= n; i++) {
        cin >> a[i];
    }
  
    int ans = -2e9;
    for (int i = 0; i <= n; i++) {
        int j = (i + 1) % (n + 1);
        ans = max(ans, a[i] + a[j]);
    }
    cout << ans << endl;
}

int main() {
    solve();
    return 0;
}
```

**复杂度分析**
- 时间复杂度：\( O(n) \)

# B. Card Game

**链接**
* 暂无在线评测链接，来源于2026牛客寒假集训营第一场

## 题目

两人各有 \( n \) 张牌，小苯的牌为排列 \( a \)，小红的牌为排列 \( b \)。游戏规则：比较两人当前最前一张牌，数字大的一方得一分并移除该牌。小苯可以在游戏开始前重排自己的牌以最大化得分，求能得到最高分的重排方案数。

## 方法

### 方法一：贪心+组合数学

**思路和算法**

1. 首先求出小苯能得到的最高分：将 \( a \) 降序排列时，得分等于 \( a \) 中大于 \( b \) 的最小值的数字个数。
2. 设 \( mn = \min(b) \)，统计 \( a \) 中大于 \( mn \) 的数字个数 \( x \) 和小于等于 \( mn \) 的数字个数 \( y \)。
3. 要得到最高分，必须将所有大于 \( mn \) 的数字放在前面（任意排列），所有小于等于 \( mn \) 的数字放在后面（任意排列）。
4. 方案数为 \( x! \times y! \)。

**代码**

```cpp
#include <iostream>
#include <vector>
#include <algorithm>
using namespace std;
const int MOD = 1e9 + 7;

void solve() {
    int n;
    cin >> n;
    vector<int> a(n);
    for (int i = 0; i < n; i++) cin >> a[i];
  
    int mn_b = 2e9;
    for (int i = 0; i < n; i++) {
        int x;
        cin >> x;
        mn_b = min(mn_b, x);
    }
  
    int x = 0, y = 0;
    for (int i = 0; i < n; i++) {
        if (a[i] > mn_b) x++;
        else y++;
    }
  
    long long ans = 1;
    for (int i = 1; i <= x; i++) ans = ans * i % MOD;
    for (int i = 1; i <= y; i++) ans = ans * i % MOD;
  
    cout << ans << endl;
}

int main() {
    solve();
    return 0;
}
```

**复杂度分析**
- 时间复杂度：\( O(n) \)
- 空间复杂度：\( O(n) \)

# A. A+B Problem

**链接**
* 暂无在线评测链接，来源于2026牛客寒假集训营第一场

## 题目

有八个独立的七段码显示器，每个显示器的7个二极管被点亮的概率给定，互相独立。求四个显示器显示一个四位数字 \( A \)，另外四个显示一个四位数字 \( B \)，且 \( A + B = C \)（给定常数）的概率。

## 方法

### 方法一：状态压缩+枚举

**思路和算法**

1. 预处理每个数字0-9对应的点亮状态（二进制压缩）。
2. 计算单个显示器显示数字 \( d \) 的概率：对于数字 \( d \) 需要点亮的段，乘上点亮概率；不需要点亮的段，乘上不点亮概率。
3. 四个显示器显示四位数 \( X \) 的概率：将 \( X \) 的每一位对应的概率相乘（注意前导0的处理）。
4. 枚举 \( A \) 从0到 \( C \)，\( B = C - A \)，计算概率并累加。

**代码**

```cpp
#include <iostream>
#include <vector>
#include <string>
using namespace std;
const int MOD = 1e9 + 7;

int qpow(int a, int b) {
    int res = 1;
    while (b) {
        if (b & 1) res = 1LL * res * a % MOD;
        a = 1LL * a * a % MOD;
        b >>= 1;
    }
    return res;
}

int S[10];
void init() {
    S[0] = (1 << 0) | (1 << 1) | (1 << 2) | (1 << 4) | (1 << 5) | (1 << 6);
    S[1] = (1 << 2) | (1 << 5);
    S[2] = (1 << 0) | (1 << 2) | (1 << 3) | (1 << 4) | (1 << 6);
    S[3] = (1 << 0) | (1 << 2) | (1 << 3) | (1 << 5) | (1 << 6);
    S[4] = (1 << 1) | (1 << 2) | (1 << 3) | (1 << 5);
    S[5] = (1 << 0) | (1 << 1) | (1 << 3) | (1 << 5) | (1 << 6);
    S[6] = (1 << 0) | (1 << 1) | (1 << 3) | (1 << 4) | (1 << 5) | (1 << 6);
    S[7] = (1 << 0) | (1 << 2) | (1 << 5);
    S[8] = (1 << 0) | (1 << 1) | (1 << 2) | (1 << 3) | (1 << 4) | (1 << 5) | (1 << 6);
    S[9] = (1 << 0) | (1 << 1) | (1 << 2) | (1 << 3) | (1 << 5) | (1 << 6);
}

void solve() {
    init();
    int C;
    cin >> C;
    vector<int> p(7);
    int inv100 = qpow(100, MOD - 2);
    for (int i = 0; i < 7; i++) {
        cin >> p[i];
        p[i] = 1LL * p[i] * inv100 % MOD;
    }
  
    vector<int> digit(10, 1);
    for (int i = 0; i < 10; i++) {
        for (int j = 0; j < 7; j++) {
            if (S[i] >> j & 1) {
                digit[i] = 1LL * digit[i] * p[j] % MOD;
            } else {
                digit[i] = 1LL * digit[i] * (1 + MOD - p[j]) % MOD;
            }
        }
    }
  
    auto calc = [&](int x) -> int {
        if (x == 0) {
            int res = digit[0];
            for (int i = 0; i < 3; i++) res = 1LL * res * digit[0] % MOD;
            return res;
        }
        int res = 1;
        int len = 0;
        while (x > 0) {
            res = 1LL * res * digit[x % 10] % MOD;
            x /= 10;
            len++;
        }
        for (int i = 0; i < 4 - len; i++) {
            res = 1LL * res * digit[0] % MOD;
        }
        return res;
    };
  
    int ans = 0;
    for (int A = 0; A <= C; A++) {
        int B = C - A;
        ans = (ans + 1LL * calc(A) * calc(B)) % MOD;
    }
    cout << ans << endl;
}

int main() {
    solve();
    return 0;
}
```

**复杂度分析**
- 时间复杂度：\( O(C) \)，其中 \( C \) 为输入常数
- 空间复杂度：\( O(1) \)

# G. Digital Folding

**链接**
* 暂无在线评测链接，来源于2026牛客寒假集训营第一场

## 题目

定义正整数 \( x \) 的折叠数为：将其十进制数位翻转并去除前导0后得到的新数。给定区间 \([l, r]\)，求区间内所有整数的折叠数的最大值。

## 方法

### 方法一：分类讨论+构造

**思路和算法**

1. 特判：如果 \( r \) 是形如 \(100\ldots0\)（即 \(10^k\)），则当 \( l = r \) 时答案为1，否则答案为 \( r-1 \)。
2. 否则，答案的位数等于 \( r \) 的位数。将 \( l \) 调整到与 \( r \) 同位数的最小值（即 \(10^{len-1}+1\)，其中 \( len \) 是 \( r \) 的位数）。
3. 从高位到低位找到第一个 \( l \) 和 \( r \) 不同的位置 \( k \)：
   - 如果不存在（即 \( l = r \)），答案就是 \( l \) 去掉末尾0后翻转。
   - 否则，构造答案：高位与 \( l \) 相同，第 \( k \) 位取 \( r[k] - 1 \)，后面所有位取9。

**代码**

```cpp
#include <iostream>
#include <string>
#include <algorithm>
using namespace std;

void solve() {
    string L, R;
    cin >> L >> R;
  
    // 特判 R = 100...0
    if (R[0] == '1' && count(R.begin(), R.end(), '0') == R.size() - 1) {
        if (L == R) {
            cout << "1\n";
        } else {
            long long x = stoll(R);
            cout << x - 1 << "\n";
        }
        return;
    }
  
    // 调整 L 与 R 同位数
    if (L.size() < R.size()) {
        L = "1" + string(R.size() - 1, '0');
        L.back() = '1';
    }
  
    int n = R.size();
    int k = -1;
    for (int i = 0; i < n; i++) {
        if (L[i] != R[i]) {
            k = i;
            break;
        }
    }
  
    string ans;
    if (k == -1) {  // L == R
        ans = L;
        while (ans.back() == '0') ans.pop_back();
        reverse(ans.begin(), ans.end());
    } else {
        // 高位与 L 相同
        for (int i = 0; i < k; i++) ans += L[i];
        // 第 k 位
        bool ok = true;
        for (int i = k + 1; i < n; i++) {
            if (R[i] != '9') ok = false;
        }
        ans += (R[k] - !ok);
        // 后面全 9
        for (int i = k + 1; i < n; i++) ans += '9';
    }
    cout << ans << "\n";
}

int main() {
    solve();
    return 0;
}
```

**复杂度分析**
- 时间复杂度：\( O(\log r) \)
- 空间复杂度：\( O(\log r) \)

# H. Blackboard

**链接**
* 暂无在线评测链接，来源于2026牛客寒假集训营第一场

## 题目

黑板上写有计算式 \( a_1 + a_2 + \cdots + a_n \)，可以将一些加号擦成按位或（|）。求有多少种擦法使得新算式的结果与原算式结果相同。

## 方法

### 方法一：动态规划

**思路和算法**

定义 \( dp[i] \) 表示前 \( i \) 个数字组成的表达式的合法方案数。转移时，向前找到所有满足条件的 \( j \)：
- \( (a_j | a_{j+1} | \cdots | a_i) = a_j + a_{j+1} + \cdots + a_i \)
即这段区间按位或等于算术和，这意味着这些数字的二进制位互不重叠。

维护前缀和数组 \( s \) 加速转移。同时用链表快速找到满足条件的最左位置。

**代码**

```cpp
#include <iostream>
#include <vector>
using namespace std;
const int MOD = 1e9 + 7;

void solve() {
    int n;
    cin >> n;
    vector<int> a(n + 1), pre(n + 1);
    int lst = 0;
    for (int i = 1; i <= n; i++) {
        cin >> a[i];
        pre[i] = lst;
        if (a[i] > 0) lst = i;
    }
  
    vector<int> dp(n + 2, 0), s(n + 2, 0);
    dp[1] = 1;
    s[1] = 1;
  
    for (int i = 1; i <= n; i++) {
        int j = i;
        int val = 0;
        while (j > 0 && (val & a[j]) == 0) {
            val |= a[j];
            j = pre[j];
        }
        dp[i + 1] = (s[i] - s[j] + MOD) % MOD;
        s[i + 1] = (s[i] + dp[i + 1]) % MOD;
    }
  
    cout << dp[n + 1] << endl;
}

int main() {
    solve();
    return 0;
}
```

**复杂度分析**
- 时间复杂度：\( O(n \cdot \log \max(a_i)) \)，因为每个数字最多被访问其二进制位数次
- 空间复杂度：\( O(n) \)

# D. Sequence Coloring

**链接**
* 暂无在线评测链接，来源于2026牛客寒假集训营第一场

## 题目

长度为 \( n \) 的序列，白色数字值为正，黑色数字值为0。开始时可以选择 \( k \) 个白色数字染红，之后每秒：所有红色数字将其右侧 \( a_i \) 个元素中的白色数字染红。求将所有白色数字染红的最短时间。

## 方法

### 方法一：二分答案+贪心

**思路和算法**

1. 答案具有单调性，二分时间 \( mid \)。
2. 检查函数：贪心从左到右染色，维护当前已染色个数和当前红色点的传播时间。
3. 预处理每个位置能跳到的最远位置 \( nxt[i] = \max(nxt[i-1], i + a[i]) \)。
4. 模拟传播过程，计算需要手动染色的点数是否不超过 \( k \)。

**代码**

```cpp
#include <iostream>
#include <vector>
#include <algorithm>
using namespace std;

bool check(int mid, int n, int k, vector<int>& a, vector<int>& nxt) {
    int i = 1;
    while (i <= n && a[i] == 0) i++;
    if (i > n) return true;
  
    int used = 1, tim = 0;
    while (i <= n) {
        tim++;
        i = nxt[i];
        if (i >= n) break;
        if (i == nxt[i]) {
            while (i <= n && i == nxt[i]) i++;
            if (i <= n) {
                tim = 0;
                used++;
            }
        } else {
            if (tim == mid) {
                i++;
                while (i <= n && a[i] == 0) i++;
                if (i <= n) {
                    tim = 0;
                    used++;
                }
            }
        }
    }
    return used <= k;
}

void solve() {
    int n, k;
    cin >> n >> k;
    vector<int> a(n + 1), nxt(n + 1);
    int white_cnt = 0;
    for (int i = 1; i <= n; i++) {
        cin >> a[i];
        if (a[i] > 0) white_cnt++;
        nxt[i] = max(nxt[i - 1], i + a[i]);
    }
  
    if (white_cnt <= k) {
        cout << "0\n";
        return;
    }
  
    int l = 1, r = n, ans = -1;
    while (l <= r) {
        int mid = (l + r) / 2;
        if (check(mid, n, k, a, nxt)) {
            ans = mid;
            r = mid - 1;
        } else {
            l = mid + 1;
        }
    }
    cout << ans << "\n";
}

int main() {
    solve();
    return 0;
}
```

**复杂度分析**
- 时间复杂度：\( O(n \log n) \)
- 空间复杂度：\( O(n) \)

# I. AND vs MEX

**链接**
* 暂无在线评测链接，来源于2026牛客寒假集训营第一场

## 题目

初始有空集合 \( S \)，可以从区间 \([L, R]\) 中选择若干个不同整数，将它们的按位与加入 \( S \)。求 \( S \) 的 MEX 的最大值。

## 方法

### 方法一：分类讨论+构造

**思路和算法**

设 \( highbit(x) \) 为 \( x \) 的最高位位置。令 \( b_1 = highbit(L) \)，\( b_2 = highbit(R) \)。
1. 如果 \( L = 0 \)，答案为 \( R+1 \)。
2. 如果 \( b_1 = b_2 \)，答案为 0（因为所有数字最高位相同，与结果该位始终为1）。
3. 如果 \( b_2 > b_1 + 1 \)，答案为 \( R+1 \)（可以构造出0到 \( R \) 的所有数字）。
4. 否则 \( b_2 = b_1 + 1 \)：
   - 计算 \( ans = R - 2^{b_2} + 1 \)（即用 \( [2^{b_2}, R] \) 中的数与 \( 2^{b_1} \) 相与得到的数字）
   - 计算 \( L \) 能构造的下限 \( low \)：从 \( b_1 \) 位向下，找到第一个0位，将其右侧所有位置1
   - 如果 \( low \leq ans \)，说明有交集，答案为 \( R+1 \)；否则答案为 \( ans \)

**代码**

```cpp
#include <iostream>
using namespace std;

int highbit(long long x) {
    for (int i = 60; i >= 0; i--) {
        if (x >> i & 1) return i;
    }
    return -1;
}

void solve() {
    long long L, R;
    cin >> L >> R;
    int b1 = highbit(L), b2 = highbit(R);
  
    if (b1 == -1) {  // L == 0
        cout << R + 1 << "\n";
    } else if (b1 == b2) {
        cout << "0\n";
    } else if (b2 > b1 + 1) {
        cout << R + 1 << "\n";
    } else {
        long long ans = R - (1LL << b2) + 1;
        long long low = 0;
        for (int j = b1; j >= 0; j--) {
            if (((L >> j) & 1) == 0) break;
            low |= (1LL << j);
        }
        if (low <= ans) {
            ans = R + 1;
        }
        cout << ans << "\n";
    }
}

int main() {
    solve();
    return 0;
}
```

**复杂度分析**
- 时间复杂度：\( O(\log R) \)
- 空间复杂度：\( O(1) \)

# F. Permutation Counting

**链接**
* 暂无在线评测链接，来源于2026牛客寒假集训营第一场

## 题目

给定 \( m \) 条信息 \( (l_i, r_i, k_i) \)，表示排列在区间 \([l_i, r_i]\) 中的最大值为 \( k_i \)。求长度为 \( n \) 且符合所有信息的排列个数。

## 方法

### 方法一：链式并查集+组合数学

**思路和算法**

1. 对每个 \( k \)，维护其必须出现的区间交集 \( [L_1, R_1] \) 和可能出现的区间并集 \( [L_2, R_2] \)。
2. 从小到大处理每个 \( k \)：
   - 在交集区间中选一个位置放 \( k \)（可用位置数用并查集维护）
   - 在并集区间中放小于 \( k \) 的数字（从剩余数字中选，排列数计算）
3. 用链式并查集维护已占用位置，实现 \( O(\alpha(n)) \) 的区间查询和修改。
4. 最后剩余数字全排列乘到答案中。

**代码**

```cpp
#include <iostream>
#include <vector>
#include <numeric>
#include <algorithm>
using namespace std;
const int MOD = 1e9 + 7;
const int N = 2e6 + 10;

long long fac[N], inv[N];

long long qpow(long long a, long long b) {
    long long res = 1;
    while (b) {
        if (b & 1) res = res * a % MOD;
        a = a * a % MOD;
        b >>= 1;
    }
    return res;
}

void init() {
    fac[0] = 1;
    for (int i = 1; i < N; i++) fac[i] = fac[i - 1] * i % MOD;
    inv[N - 1] = qpow(fac[N - 1], MOD - 2);
    for (int i = N - 2; i >= 0; i--) inv[i] = inv[i + 1] * (i + 1) % MOD;
}

long long A(int a, int b) {
    if (a < b) return 0;
    return fac[a] * inv[a - b] % MOD;
}

void solve() {
    init();
    int n, m;
    cin >> n >> m;
  
    vector<int> L1(n + 1, 0), R1(n + 1, n + 1);
    vector<int> L2(n + 1, n + 1), R2(n + 1, -1);
  
    for (int i = 0; i < m; i++) {
        int l, r, k;
        cin >> l >> r >> k;
        if (R1[k] < l || L1[k] > r) {
            cout << "0\n";
            return;
        }
        L1[k] = max(L1[k], l);
        R1[k] = min(R1[k], r);
        L2[k] = min(L2[k], l);
        R2[k] = max(R2[k], r);
    }
  
    vector<int> fa(n + 2);
    iota(fa.begin(), fa.end(), 0);
  
    function<int(int)> find = [&](int x) {
        while (x != fa[x]) x = fa[x] = fa[fa[x]];
        return x;
    };
  
    auto merge = [&](int a, int b) {
        a = find(a);
        b = find(b);
        if (a > b) swap(a, b);
        fa[a] = b;
    };
  
    long long ans = 1;
    int lst = 1, cnt = 0;
  
    for (int k = 1; k <= n; k++) {
        if (R2[k] == -1) continue;
      
        // 在交集区间选位置放 k
        int L = L1[k], R = R1[k];
        int cur = L, mx_pos = 0;
        while (cur <= R) {
            int nxt = find(cur) + 1;
            if (cur + 1 == nxt) {
                mx_pos++;
                merge(cur, nxt);
            }
            cur = find(cur);
        }
        ans = ans * mx_pos % MOD;
      
        // 在并集区间放小于 k 的数字
        L = L2[k], R = R2[k];
        int pos = mx_pos - 1;  // 除去 k 本身的位置数
        cur = L;
        while (cur <= R) {
            int nxt = find(cur) + 1;
            if (cur + 1 == nxt) {
                pos++;
                merge(cur, nxt);
            }
            cur = find(cur);
        }
      
        cnt += k - lst;  // 需要填的数字个数
        ans = ans * A(cnt, pos) % MOD;
        lst = k + 1;
        cnt -= pos;
    }
  
    cnt += n - lst + 1;
    ans = ans * fac[cnt] % MOD;
    cout << ans << "\n";
}

int main() {
    solve();
    return 0;
}
```

**复杂度分析**
- 时间复杂度：\( O(n \alpha(n)) \)，其中 \( \alpha \) 是反阿克曼函数
- 空间复杂度：\( O(n) \)

# J. MST Problem

**链接**
* 暂无在线评测链接，来源于2026牛客寒假集训营第一场

## 题目

\( n \) 个点的无向完全图，点权为 \( a_i \)，边权为 \( a_u + a_v \)。删除给定的 \( m \) 条边后，求最小生成树权重，或判断不存在。

## 方法

### 方法一：线段树优化的Prim算法

**思路和算法**

1. 在完全图上跑Prim算法，需要快速找到当前连通块到未连通点的最小边。
2. 用线段树维护每个未连通点连接到当前连通块的最小边权：
   - 节点维护两个值：该点的点权，以及 min(点权 + 连通块中某点点权)
   - 当新加入点 \( u \) 时，对所有未连通点 \( v \)，用 \( a_u + a_v \) 更新 \( v \) 的最小边权
3. 由于有删边，需要排除不能连的边：对每个点维护其禁止连接的邻点集合，区间更新时跳过这些点。
4. 线段树支持区间取min和全局查询最小值。

**代码**

```cpp
#include <iostream>
#include <vector>
#include <set>
#include <algorithm>
using namespace std;
typedef long long ll;
const ll INF = 1e18;
const int N = 3e5 + 10;

struct Node {
    int l, r;
    ll lz;  // 区间中所有点能取到的连通块内最小点权
    pair<ll, int> vertex;  // (点权, 点编号)
    pair<ll, int> edge;    // (最小边权, 对应点编号)
} tr[N * 4];

int n, m;
int a[N];
vector<int> bad[N];

void push_up(int u) {
    tr[u].edge = min(tr[u * 2].edge, tr[u * 2 + 1].edge);
    tr[u].vertex = min(tr[u * 2].vertex, tr[u * 2 + 1].vertex);
}

void build(int u, int l, int r) {
    tr[u] = {l, r, INF, {a[l], l}, {a[l] + INF, l}};
    if (l == r) return;
    int mid = (l + r) / 2;
    build(u * 2, l, mid);
    build(u * 2 + 1, mid + 1, r);
    push_up(u);
}

void push_down(int u) {
    if (tr[u].lz != INF) {
        for (int son : {u * 2, u * 2 + 1}) {
            if (tr[son].lz > tr[u].lz) {
                tr[son].lz = tr[u].lz;
                if (tr[son].vertex.first + tr[u].lz < tr[son].edge.first) {
                    tr[son].edge = {tr[son].vertex.first + tr[u].lz, tr[son].vertex.second};
                }
            }
        }
    }
}

void update(int u, int l, int r, ll v) {
    if (tr[u].l >= l && tr[u].r <= r) {
        if (tr[u].lz <= v) return;
        tr[u].lz = v;
        if (tr[u].vertex.first + v < tr[u].edge.first) {
            tr[u].edge = {tr[u].vertex.first + v, tr[u].vertex.second};
        }
        return;
    }
    push_down(u);
    int mid = (tr[u].l + tr[u].r) / 2;
    if (l <= mid) update(u * 2, l, r, v);
    if (r > mid) update(u * 2 + 1, l, r, v);
    push_up(u);
}

void del(int u, int k) {
    if (tr[u].l == tr[u].r) {
        tr[u].vertex = {INF, k};
        tr[u].edge = {INF, k};
        return;
    }
    push_down(u);
    int mid = (tr[u].l + tr[u].r) / 2;
    if (k <= mid) del(u * 2, k);
    else del(u * 2 + 1, k);
    push_up(u);
}

void solve() {
    cin >> n >> m;
    int idx = -1, mn = 2e9;
    for (int i = 1; i <= n; i++) {
        cin >> a[i];
        if (a[i] < mn) {
            mn = a[i];
            idx = i;
        }
        bad[i].clear();
        bad[i].push_back(0);
    }
  
    for (int i = 0; i < m; i++) {
        int u, v;
        cin >> u >> v;
        bad[u].push_back(v);
        bad[v].push_back(u);
    }
  
    for (int i = 1; i <= n; i++) {
        bad[i].push_back(i);
        sort(bad[i].begin(), bad[i].end());
    }
  
    build(1, 1, n);
    ll ans = 0;
  
    for (int i = 0; i < n - 1; i++) {
        del(1, idx);
      
        int l = 0;
        for (int r : bad[idx]) {
            if (l + 1 <= r - 1) {
                update(1, l + 1, r - 1, a[idx]);
            }
            l = r;
        }
        if (l + 1 <= n) {
            update(1, l + 1, n, a[idx]);
        }
      
        if (tr[1].edge.first >= INF / 2) {
            cout << "-1\n";
            return;
        }
      
        ans += tr[1].edge.first;
        idx = tr[1].edge.second;
    }
  
    cout << ans << "\n";
}

int main() {
    solve();
    return 0;
}
```

**复杂度分析**
- 时间复杂度：\( O((n+m)\log n) \)
- 空间复杂度：\( O(n+m) \)
