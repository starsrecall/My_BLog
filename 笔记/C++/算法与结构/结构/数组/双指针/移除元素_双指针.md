# 移除元素_双指针

## 问题重述

给定一个数组 `nums` 和一个值 `val`，你需要原地移除所有数值等于 `val` 的元素，并返回移除后数组的新长度。

**核心要求**：
- 仅使用 O(1) 额外空间
- 原地修改输入数组
- 元素的顺序可以改变
- 不考虑数组中超出新长度后面的元素

## 理解数组的内存特性

**关键认知**：数组元素在内存中是连续存储的，不能单独删除某个元素，只能通过覆盖来实现"移除"。

## 方法一：暴力解法（两层循环）

### 算法思路
使用两层循环遍历数组：
1. 外层循环遍历每个元素
2. 当找到等于 `val` 的元素时，内层循环将后续所有元素向前移动一位

### 代码实现
```cpp
class Solution {
public:
    int removeElement(vector<int>& nums, int val) {
        int size = nums.size();
        for (int i = 0; i < size; i++) {
            if (nums[i] == val) {
                // 将i之后的所有元素前移一位
                for (int j = i + 1; j < size; j++) {
                    nums[j - 1] = nums[j];
                }
                i--;    // 因元素前移，i位置已更新，需重新检查
                size--; // 有效数组长度减1
            }
        }
        return size;
    }
};
```

### 复杂度分析
- **时间复杂度**：O(n²)，最坏情况下每个元素都需要移动
- **空间复杂度**：O(1)，只使用了常数个额外变量

### 适用场景
- 数据规模较小
- 对算法效率要求不高
- 需要保持元素相对顺序

## 方法二：双指针法（快慢指针）

### 算法思路
使用两个指针在一个循环内完成工作：
- **右指针（快指针）**：遍历原数组，寻找新数组（不含 `val` 的数组）的元素
- **左指针（慢指针）**：指向新数组的下一个插入位置

**循环不变量**：区间 `[0, left)` 中的元素都不等于 `val`

### 执行过程分析
1. 初始化 `left = 0`
2. 遍历数组，`right` 从 0 到 `n-1`
3. 当 `nums[right] != val` 时：
   - 将 `nums[right]` 复制到 `nums[left]`
   - `left` 右移一位
4. 遍历结束后，`left` 即为新数组长度

### 代码实现
```cpp
class Solution {
public:
    int removeElement(vector<int>& nums, int val) {
        int n = nums.size();
        int left = 0;
        for (int right = 0; right < n; right++) {
            if (nums[right] != val) {
                nums[left] = nums[right];
                left++;
            }
        }
        return left;
    }
};
```

### 算法正确性证明
**数学归纳法证明**：
1. **初始条件**：当 `right = 0` 时，区间 `[0, left)` 为空，显然不含 `val`
2. **归纳假设**：假设在第 `k` 步时，区间 `[0, left)` 中的元素都不等于 `val`
3. **归纳步骤**：
   - 若 `nums[right] != val`：将其放入 `nums[left]`，然后 `left++`，区间 `[0, left)` 仍不含 `val`
   - 若 `nums[right] == val`：直接跳过，区间 `[0, left)` 不变
4. **终止条件**：当 `right = n` 时，遍历结束，`left` 即为不含 `val` 的元素个数

### 复杂度分析
- **时间复杂度**：O(n)，每个元素最多被处理一次
- **空间复杂度**：O(1)，只使用了常数个额外变量

### 优缺点
**优点**：
- 时间复杂度优化到 O(n)
- 保持了元素的相对顺序
- 代码简洁易懂

**缺点**：
- 当 `val` 元素很少时，仍需要 n 次赋值操作

## 方法三：双指针优化（相向指针）

### 算法思路
当要移除的元素很少时，可以通过从两端向中间遍历的方式优化：
- **左指针**：从数组开头向中间移动
- **右指针**：从数组末尾向中间移动

**核心优化点**：当左指针遇到要删除的元素时，用右指针指向的元素覆盖它，而不是移动所有后续元素。

### 执行过程分析
以 `nums = [1,2,3,4,5], val = 1` 为例：
1. 初始：`left = 0`, `right = 5`
2. `nums[0] == 1`：用 `nums[4] = 5` 覆盖，`right--` → `right = 4`
3. `nums[0] = 5`，现在数组为 `[5,2,3,4,5]`
4. 继续检查 `nums[0] = 5 != 1`，`left++` → `left = 1`
5. 最终结果：`[5,2,3,4,5]`，有效长度 `left = 1`

### 代码实现
```cpp
class Solution {
public:
    int removeElement(vector<int>& nums, int val) {
        int left = 0, right = nums.size();
        while (left < right) {
            if (nums[left] == val) {
                // 用右指针元素覆盖左指针元素
                nums[left] = nums[right - 1];
                right--; // 缩小有效数组范围
            } else {
                left++; // 左指针右移
            }
        }
        return left;
    }
};
```

### 算法正确性证明
**循环不变量**：区间 `[0, left)` 中的元素都不等于 `val`，区间 `[right, n)` 中的元素可能是任意值（包括 `val`）

**证明思路**：
1. 初始时，`[0, left)` 为空，`[right, n)` 为整个数组，满足条件
2. 每次迭代：
   - 若 `nums[left] == val`：用 `nums[right-1]` 覆盖，`right--`，区间 `[0, left)` 不变，`[right, n)` 缩小
   - 若 `nums[left] != val`：`left++`，区间 `[0, left)` 扩大一个元素
3. 终止时 `left == right`，区间 `[0, left)` 即为新数组

### 复杂度分析
- **时间复杂度**：O(n)，每个元素最多被访问一次
- **空间复杂度**：O(1)，只使用了常数个额外变量

### 性能分析
- **最佳情况**：数组中没有 `val` 元素，时间复杂度 O(n)，但只进行比较操作，无赋值
- **最坏情况**：数组中所有元素都是 `val`，时间复杂度 O(n)，每个元素被赋值一次
- **平均情况**：取决于 `val` 元素的分布

### 与快慢指针法的对比
| 对比维度   | 快慢指针法   | 相向指针法                  |
| ---------- | ------------ | --------------------------- |
| 时间复杂度 | O(n)         | O(n)                        |
| 赋值次数   | 最多 n 次    | 最多 k 次（k为val元素个数） |
| 元素顺序   | 保持原有顺序 | 可能改变顺序                |
| 适用场景   | 一般情况     | val元素较少时               |

## 算法选择策略

### 根据问题特征选择算法
1. **需要保持元素顺序**：选择快慢指针法
2. **val元素很少**：选择相向指针法
3. **数据规模小**：暴力解法也可接受
4. **对内存有严格限制**：所有方法都满足 O(1) 空间复杂度

### 性能实测对比
通过实际测试不同规模的数据，可以观察到：
- 当 `val` 元素占比 < 10% 时，相向指针法有明显优势
- 当需要保持顺序时，只能选择快慢指针法
- 数据规模 < 1000 时，三种方法差异不大

## 边界条件处理

### 特殊输入情况
1. **空数组**：直接返回 0
2. **所有元素都等于val**：返回 0
3. **没有元素等于val**：返回原数组长度
4. **val不在数组中**：返回原数组长度

### 代码鲁棒性增强
```cpp
class Solution {
public:
    int removeElement(vector<int>& nums, int val) {
        // 处理空数组
        if (nums.empty()) return 0;
      
        // 处理特殊情况：所有元素都等于val
        bool allVal = true;
        for (int num : nums) {
            if (num != val) {
                allVal = false;
                break;
            }
        }
        if (allVal) return 0;
      
        // 根据实际情况选择算法
        // 这里以快慢指针为例
        int left = 0;
        for (int right = 0; right < nums.size(); right++) {
            if (nums[right] != val) {
                nums[left++] = nums[right];
            }
        }
        return left;
    }
};
```

>
> 鲁棒性是衡量软件在面对各种异常情况、错误输入、系统故障或环境变化时的应对能力。一个鲁棒的系统能够在不确定性和意外事件面前保持稳定运行，并有效地处理问题，以防止系统崩溃或行为异常。
