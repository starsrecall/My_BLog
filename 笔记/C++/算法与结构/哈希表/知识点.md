# C++ 哈希表核心知识点完全指南

## 📚 一、哈希表基础概念

### 核心概念详解

| 知识点           | 说明                                                 | 技术细节                                                     |
| ---------------- | ---------------------------------------------------- | ------------------------------------------------------------ |
| **哈希函数**     | 将任意长度的输入（键）映射为固定长度的哈希值（整数） | 标准库为常见类型（int、string等）提供了特化的 `std::hash`    |
| **哈希冲突**     | 不同键产生相同哈希值                                 | `unordered_map` 使用链地址法，每个桶是一个链表，现代实现可能在小桶时用线性探测 |
| **桶（Bucket）** | 哈希表内部数组的元素，存储相同哈希值的元素           | 桶的数量直接影响性能，可通过 `bucket_count()` 获取           |
| **负载因子**     | 元素数/桶数，衡量哈希表拥挤程度                      | 默认最大负载因子为 1.0，超过会触发 rehash                    |

## 🛠️ 二、C++ 中的哈希表容器家族

### 容器特性对比

```cpp
#include <unordered_map>
#include <unordered_set>
#include <map>
#include <set>

// 有序 vs 无序容器对比
std::map<std::string, int> ordered_map;        // 基于红黑树，按键排序
std::unordered_map<std::string, int> hash_map; // 基于哈希表，无序但更快

std::set<int> ordered_set;                     // 有序集合
std::unordered_set<int> hash_set;              // 无序集合
```

### 选择指南
- **需要有序遍历**：使用 `map`/`set`
- **需要极速查找**：使用 `unordered_map`/`unordered_set`
- **允许重复键**：使用 `multi` 版本
- **内存敏感**：`map`/`set` 通常占用更少内存

```cpp
std::unordered_map<std::string, int> inventory = {{"apple", 10}, {"banana", 5}};

// 模式1：使用 find（最安全，不修改容器）
auto it = inventory.find("apple");

    std::cout << "库存：" << it->second << std::endl;
```

### 4. 删除元素（高效删除技巧）

```cpp
std::unordered_set<int> numbers = {1, 2, 3, 4, 5};

// 删除并获取下一个迭代器（避免迭代器失效问题）
for (auto it = numbers.begin(); it != numbers.end(); /* 不在这里递增 */) {
    if (*it % 2 == 0) {
        it = numbers.erase(it);  // erase 返回下一个有效迭代器
    } else {
        ++it;
    }
}

// 批量删除
std::unordered_set<int> to_remove = {1, 3};
for (int num : to_remove) {
    numbers.erase(num);
}

if (numbers.contains(5)) {
    numbers.erase(5);
}
```

```cpp
std::unordered_map<int, std::string> data;
```

## 🔧 五、自定义类型作为键（完整示例）

### 完整自定义键实现

```cpp
#include <string>
#include <functional>

class Employee {
private:
    int id;
    std::string name;
  
public:
    Employee(int id, std::string name) : id(id), name(std::move(name)) {}
  
    // 必须提供相等比较
    bool operator==(const Employee& other) const {
        return id == other.id && name == other.name;
    }
  
    // 辅助方法
    int getId() const { return id; }
    const std::string& getName() const { return name; }
};

// 自定义哈希函数
struct EmployeeHash {
    std::size_t operator()(const Employee& emp) const {
        // 组合多个字段的哈希
        std::size_t h1 = std::hash<int>()(emp.getId());
        std::size_t h2 = std::hash<std::string>()(emp.getName());
      
        // 使用 boost::hash_combine 类似的技术
        return h1 ^ (h2 << 1);
    }
};

// 使用示例
int main() {
    std::unordered_map<Employee, std::string, EmployeeHash> employee_department;
  
    employee_department.emplace(Employee(1, "Alice"), "Engineering");
    employee_department.emplace(Employee(2, "Bob"), "Marketing");
  
    // 查找
    Employee alice(1, "Alice");
    auto it = employee_department.find(alice);
    if (it != employee_department.end()) {
        std::cout << "Department: " << it->second << std::endl;
    }
  
    return 0;
}
```

### 使用 Lambda 表达式作为哈希函数

```cpp
#include <functional>

auto hash = [](const Employee& emp) {
    return std::hash<int>()(emp.getId()) ^ 
           (std::hash<std::string>()(emp.getName()) << 1);
};

auto equal = [](const Employee& a, const Employee& b) {
    return a.getId() == b.getId() && a.getName() == b.getName();
};

// C++20 可以使用透明哈希

    custom_map(10, hash, equal);
```

## 🧪 六、实战案例集锦

### 案例1：LRU缓存实现

```cpp
#include <unordered_map>
#include <list>

template<typename K, typename V>
class LRUCache {
private:
    size_t capacity;
    std::list<std::pair<K, V>> cache_list;
    std::unordered_map<K, typename std::list<std::pair<K, V>>::iterator> cache_map;
  
public:
    LRUCache(size_t cap) : capacity(cap) {}
  
    V get(const K& key) {
        auto it = cache_map.find(key);
        if (it == cache_map.end()) {
            return V();  // 返回默认值
        }
      
        // 移动到列表头部（最近使用）
        cache_list.splice(cache_list.begin(), cache_list, it->second);
        return it->second->second;
    }
  
    void put(const K& key, const V& value) {
        auto it = cache_map.find(key);
        if (it != cache_map.end()) {
            // 更新值并移动到头部
            it->second->second = value;
            cache_list.splice(cache_list.begin(), cache_list, it->second);
            return;
        }
      
        // 检查容量
        if (cache_map.size() >= capacity) {
            // 移除最久未使用
            auto last = cache_list.end();
            last--;
            cache_map.erase(last->first);
            cache_list.pop_back();
        }
      
        // 插入新元素
        cache_list.emplace_front(key, value);
        cache_map[key] = cache_list.begin();
    }
};
```

### 案例2：两数之和问题

```cpp
#include <vector>
#include <unordered_map>

std::vector<int> twoSum(const std::vector<int>& nums, int target) {
    std::unordered_map<int, int> num_index;
  
    for (int i = 0; i < nums.size(); ++i) {
        int complement = target - nums[i];
      
        auto it = num_index.find(complement);
        if (it != num_index.end()) {
            return {it->second, i};
        }
      
        num_index[nums[i]] = i;
    }
  
    return {};  // 无解
}
```

### 案例3：分组异位词

```cpp
#include <vector>
#include <string>
#include <unordered_map>
#include <algorithm>

std::vector<std::vector<std::string>> groupAnagrams(
    const std::vector<std::string>& strs) {
  
    std::unordered_map<std::string, std::vector<std::string>> groups;
  
    for (const auto& str : strs) {
        std::string key = str;
        std::sort(key.begin(), key.end());  // 排序后作为键
      
        groups[key].push_back(str);
    }
  
    std::vector<std::vector<std::string>> result;
    for (auto& [_, group] : groups) {
        result.push_back(std::move(group));
    }
  
    return result;
}
```

## 💡 七、高级技巧与最佳实践

### 1. 迭代器失效规则
```cpp
std::unordered_map<int, int> map = {{1, 10}, {2, 20}, {3, 30}};

// 插入可能使所有迭代器失效（如果触发rehash）
auto it = map.find(2);
map[4] = 40;  // 可能使 it 失效

// 安全做法：在可能修改的操作后重新获取迭代器
it = map.find(2);  // 重新获取
if (it != map.end()) {
    map.erase(it);  // 删除会使指向被删除元素的迭代器失效
}
```

```cpp
#include <mutex>

class ThreadSafeMap {
private:
    std::unordered_map<int, std::string> map_;
    mutable std::mutex mutex_;
  
public:
    void insert(int key, const std::string& value) {
        std::lock_guard<std::mutex> lock(mutex_);
        map_[key] = value;
    }
  
    bool find(int key, std::string& value) const {
        std::lock_guard<std::mutex> lock(mutex_);
        auto it = map_.find(key);
        if (it != map_.end()) {
            value = it->second;
            return true;
        }
        return false;
    }
};
```

### 4. 性能监控与调试
```cpp
void analyze_map(const std::unordered_map<int, int>& map) {
    std::cout << "性能分析报告:\n";
    std::cout << "================\n";
    std::cout << "元素数量: " << map.size() << "\n";
    std::cout << "桶数量: " << map.bucket_count() << "\n";
    std::cout << "负载因子: " << map.load_factor() << "\n";
  
    // 统计桶分布
    size_t empty_buckets = 0;
    size_t max_chain_length = 0;
  
    for (size_t i = 0; i < map.bucket_count(); ++i) {
        size_t bucket_size = map.bucket_size(i);
        if (bucket_size == 0) empty_buckets++;
        if (bucket_size > max_chain_length) max_chain_length = bucket_size;
    }
  
    std::cout << "空桶比例: " 
              << (static_cast<double>(empty_buckets) / map.bucket_count()) * 100 
              << "%\n";
    std::cout << "最长链长度: " << max_chain_length << "\n";
  
    // 建议优化
    if (map.load_factor() > 0.7) {
        std::cout << "警告: 负载因子过高，考虑增加桶数量\n";
    }
    if (max_chain_length > 10) {
        std::cout << "警告: 哈希冲突严重，考虑改进哈希函数\n";
    }
}
```

## 📊 九、总结速查表

### 快速决策指南
| 场景         | 推荐容器             | 理由                 |
| ------------ | -------------------- | -------------------- |
| 需要按键排序 | `std::map`           | 红黑树保证有序性     |
| 需要快速查找 | `std::unordered_map` | 平均 O(1) 时间复杂度 |
| 内存敏感     | `std::map`           | 通常占用更少内存     |
| 需要稳定性能 | `std::map`           | 最坏情况 O(log n)    |
| 处理小数据集 | 任意                 | 差异不大             |
| 处理大数据集 | `std::unordered_map` | 性能优势明显         |
| 需要范围查询 | `std::map`           | 哈希表不支持范围查询 |

### 性能调优清单
1. ✅ 预分配空间：使用 `reserve()` 减少 rehash
2. ✅ 选择合适的哈希函数：避免过多冲突
3. ✅ 监控负载因子：保持在 0.5-0.75 之间
4. ✅ 使用移动语义：减少拷贝开销
5. ✅ 批量操作：使用范围插入/删除
6. ✅ 选择合适的键类型：简单类型性能更好

### 常见陷阱避免
```cpp
// 陷阱1：误用 operator[]

// 陷阱3：哈希函数质量差
```
