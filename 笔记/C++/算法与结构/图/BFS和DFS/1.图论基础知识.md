# 图论基础知识

## 📚 一、图的基本概念

### 1.1 图的定义
**图（Graph）** 是由顶点（Vertex/Node）和边（Edge）组成的数据结构，用来表示事物之间的关系[5]。图 G 由两个集合 V 和 E 组成，记为 G=(V,E)。其中，V 是顶点集，代表图中的各个节点；E 是边集，表示顶点之间的连接关系[6]。

### 1.2 基本术语
- **顶点（Vertex）**：图中的节点，表示事物[5]
- **边（Edge）**：连接两个顶点的线，表示关系[5]
- **路径（Path）**：从一个顶点到另一个顶点经过的边的序列[5]
- **环（Cycle）**：起点和终点相同的路径[5]
- **度（Degree）**：与顶点相连的边的数量[5]
  - **出度**：有向图中从顶点出发的边的数量
  - **入度**：有向图中指向顶点的边的数量

## 🔄 二、图的分类

### 2.1 有向图 vs 无向图
- **无向图**：边没有方向，A-B 和 B-A 是同一条边[5]
- **有向图**：边有方向，A→B 和 B→A 是不同的边[5]

### 2.2 加权图 vs 无权图
- **无权图**：边没有权重，只表示连接关系[5]
- **加权图**：边有权重，表示距离、成本等[5]

### 2.3 连通性
- **连通图**：任意两个顶点之间都存在路径[5]
- **非连通图**：存在两个顶点之间没有路径[5]
- **连通分量**：无向图中的极大连通子图[5]
- **强连通图**：有向图中任意两个顶点之间都存在双向路径[5]

## 💾 三、图的存储结构

### 3.1 邻接矩阵
适合稠密图，空间复杂度 O(V²)[5]。

```cpp
// 邻接矩阵表示
vector<vector<int>> graph(V, vector<int>(V, 0));
// graph[i][j] = 1 表示顶点i和j之间有边
```

**优点**：
- 查询两点是否相邻：O(1)
- 适合稠密图

**缺点**：
- 空间复杂度高
- 添加/删除顶点麻烦

### 3.2 邻接表
适合稀疏图，空间复杂度 O(V+E)[5]。

```cpp
// 邻接表表示
vector<vector<int>> graph(V);
// graph[i] 存储与顶点i相邻的所有顶点
```

**优点**：
- 空间效率高
- 适合稀疏图
- 添加顶点容易

**缺点**：
- 查询两点是否相邻：O(degree(v))

### 3.3 边列表
```cpp
// 存储所有边的信息
vector<pair<int, int>> edges;  // 无权边
vector<tuple<int, int, int>> edges;  // 加权边 (u, v, weight)
```

## 🔍 四、图的遍历算法

### 4.1 深度优先搜索（DFS）
**算法特点**[5][6]：
- **深度优先**：尽可能深地搜索图的分支
- **递归实现**：使用递归栈，代码简洁
- **时间复杂度**：O(V+E)
- **空间复杂度**：O(V)，递归栈的深度

**执行过程示例**：
```
图：A-B-C
    |   |
    D   E
DFS访问顺序：A → B → C → E → D
```

**代码实现**：
```cpp
void dfs(int node, vector<bool>& visited, vector<vector<int>>& graph) {
    visited[node] = true;  // 标记当前节点已访问
  
    // 遍历当前节点的所有邻居
    for (int neighbor : graph[node]) {
        if (!visited[neighbor]) {  // 如果邻居未被访问
            dfs(neighbor, visited, graph);  // 递归访问邻居
        }
    }
}
```

### 4.2 广度优先搜索（BFS）
**算法特点**[5][6]：
- **广度优先**：逐层访问，先访问距离近的节点
- **队列实现**：使用队列维护访问顺序
- **时间复杂度**：O(V+E)
- **空间复杂度**：O(V)，队列的最大长度

**执行过程示例**：
```
图：A-B-C
    |   |
    D   E
BFS访问顺序：A → B → D → C → E
层次：第0层：A
     第1层：B, D
     第2层：C, E
```

**代码实现**：
```cpp
void bfs(int start, vector<vector<int>>& graph) {
    queue<int> q;  // 队列存储待访问的节点
    vector<bool> visited(graph.size(), false);  // 标记数组
  
    q.push(start);  // 将起始节点加入队列
    visited[start] = true;  // 标记起始节点已访问
  
    while (!q.empty()) {  // 队列不为空时继续
        int node = q.front();  // 取出队首节点
        q.pop();  // 从队列中移除
      
        // 遍历当前节点的所有邻居
        for (int neighbor : graph[node]) {
            if (!visited[neighbor]) {  // 如果邻居未被访问
                visited[neighbor] = true;  // 标记邻居已访问
                q.push(neighbor);  // 将邻居加入队列
            }
        }
    }
}
```

### 4.3 DFS vs BFS 对比[5]

| 比较项         | DFS（深度优先搜索）            | BFS（广度优先搜索）          |
| -------------- | ------------------------------ | ---------------------------- |
| **搜索策略**   | 一条路走到黑（递归/栈）        | 一层一层扩展（队列）         |
| **实现方式**   | 通常用 **递归** 或 **显式栈**  | 通常用 **队列（queue）**     |
| **适用场景**   | 全路径搜索、组合问题、回溯问题 | 最短路径问题、层次遍历       |
| **空间复杂度** | 相对较小（与递归深度有关）     | 相对较大（需存整层节点）     |
| **典型应用**   | 迷宫求解、图连通分量、全排列   | 最短路径、最少步数、层序遍历 |

## 🛣️ 五、最短路径算法

### 5.1 Dijkstra算法
**特点**[1][6]：
- 单源最短路径（从单个起点到所有其他点）
- **要求**：边权非负
- **时间复杂度**：O((V+E)logV)（使用优先队列）

**算法思想**：
使用贪心策略，每次选择当前距离起点最近的未访问顶点，并更新其邻居的距离。

```cpp
// 返回从起点 start 到每个点的最短路长度 dis
vector<int> dijkstra(int n, vector<vector<pair<int, int>>>& graph, int start) {
    vector<int> dist(n, INT_MAX);
    priority_queue<pair<int, int>, vector<pair<int, int>>, greater<>> pq;
  
    dist[start] = 0;
    pq.push({0, start});
  
    while (!pq.empty()) {
        auto [d, u] = pq.top();
        pq.pop();
      
        if (d > dist[u]) continue;
      
        for (auto [v, w] : graph[u]) {
            if (dist[u] + w < dist[v]) {
                dist[v] = dist[u] + w;
                pq.push({dist[v], v});
            }
        }
    }
  
    return dist;
}
```

### 5.2 Floyd-Warshall算法
**特点**[2][6]：
- 全源最短路径（所有顶点对之间的最短路径）
- 允许负权边（但不能有负权环）
- **时间复杂度**：O(V³)

**算法思想**：
动态规划，通过中间顶点逐步优化所有顶点对的最短路径。

```cpp
// 返回一个二维列表，其中 (i,j) 这一项表示从 i 到 j 的最短路长度
vector<vector<int>> floyd(int n, vector<vector<int>>& edges) {
    vector<vector<int>> dist(n, vector<int>(n, INT_MAX));
  
    // 初始化
    for (int i = 0; i < n; i++) {
        dist[i][i] = 0;
    }
  
    for (auto& edge : edges) {
        int u = edge[0], v = edge[1], w = edge[2];
        dist[u][v] = min(dist[u][v], w);
    }
  
    // 动态规划
    for (int k = 0; k < n; k++) {
        for (int i = 0; i < n; i++) {
            for (int j = 0; j < n; j++) {
                if (dist[i][k] != INT_MAX && dist[k][j] != INT_MAX) {
                    dist[i][j] = min(dist[i][j], dist[i][k] + dist[k][j]);
                }
            }
        }
    }
  
    return dist;
}
```

### 5.3 Bellman-Ford算法
**特点**：
- 单源最短路径
- 可以处理负权边
- 可以检测负权环
- **时间复杂度**：O(VE)

## 🌳 六、最小生成树算法

### 6.1 生成树概念[1]
**生成树**：一个连通图的生成树是一个极小的连通子图，它包含图中全部的 n 个顶点，但只有构成一棵树的 n-1 条边。

**最小生成树**：所谓一个带权图的最小生成树，就是原图中边的权值最小的生成树，所谓最小是指边的权值之和小于或者等于其它生成树的边的权值之和[1]。

### 6.2 Kruskal算法
**特点**[1][6]：
- 基于边的贪心算法
- 适合稀疏图
- **时间复杂度**：O(ElogE)（主要开销在排序边）

**算法思想**：
将边按权值从小到大排序，依次选择不会形成环的边，直到选出 n-1 条边。

```cpp
// Kruskal算法核心思想
int kruskal(int n, vector<tuple<int, int, int>>& edges) {
    sort(edges.begin(), edges.end(), 
         [](auto& a, auto& b) { return get<2>(a) < get<2>(b); });
  
    UnionFind uf(n);
    int mst_weight = 0;
    int edges_used = 0;
  
    for (auto& [u, v, w] : edges) {
        if (uf.unite(u, v)) {  // 如果不在同一集合，不会形成环
            mst_weight += w;
            edges_used++;
            if (edges_used == n - 1) break;
        }
    }
  
    return mst_weight;
}
```

### 6.3 Prim算法
**特点**[1][6]：
- 基于顶点的贪心算法
- 适合稠密图
- **时间复杂度**：O(V²)（邻接矩阵）或 O(ElogV)（邻接表+优先队列）

**算法思想**：
从任意顶点开始，每次选择连接已选顶点和未选顶点之间的最小权值边，将新顶点加入已选集合。

### 6.4 Kruskal vs Prim 对比[6]

| 特性           | Prim算法          | Kruskal算法    |
| -------------- | ----------------- | -------------- |
| **适用图类型** | 稠密图            | 稀疏图         |
| **时间复杂度** | O(V²) 或 O(ElogV) | O(ElogE)       |
| **空间复杂度** | O(V)              | O(V+E)         |
| **核心操作**   | 顶点距离更新      | 边排序与环检测 |
| **实现难度**   | 相对简单          | 需要并查集     |

## 🔄 七、拓扑排序

### 7.1 概念与应用
**拓扑排序**是对有向无环图（DAG）的顶点进行排序，使得对于每一条有向边 (u, v)，u 在排序中都出现在 v 之前[2]。

**应用场景**：
- 课程安排（先修课关系）
- 任务调度（依赖关系）
- 编译顺序（文件依赖）

### 7.2 Kahn算法（基于入度）
```cpp
vector<int> topologicalSort(int n, vector<vector<int>>& edges) {
    vector<vector<int>> graph(n);
    vector<int> in_degree(n, 0);
  
    // 建图并统计入度
    for (auto& edge : edges) {
        int u = edge[0], v = edge[1];
        graph[u].push_back(v);
        in_degree[v]++;
    }
  
    // 入度为0的顶点入队
    queue<int> q;
    for (int i = 0; i < n; i++) {
        if (in_degree[i] == 0) {
            q.push(i);
        }
    }
  
    vector<int> topo_order;
    while (!q.empty()) {
        int u = q.front();
        q.pop();
        topo_order.push_back(u);
      
        // 减少邻居的入度
        for (int v : graph[u]) {
            in_degree[v]--;
            if (in_degree[v] == 0) {
                q.push(v);
            }
        }
    }
  
    // 检查是否有环
    if (topo_order.size() != n) {
        return {};  // 有环，无法拓扑排序
    }
  
    return topo_order;
}
```

## 🔗 八、并查集（Union-Find）

### 8.1 基本概念[1]
并查集是一种数据结构，用于处理一些不交集的合并及查询问题。支持两种操作：
- **查询（Find）**：查询某个元素属于哪个集合
- **合并（Union）**：将两个集合合并为一个

### 8.2 实现方式
```cpp
class UnionFind {
private:
    vector<int> parent;
    vector<int> rank;  // 用于按秩合并
  
public:
    UnionFind(int n) {
        parent.resize(n);
        rank.resize(n, 0);
        for (int i = 0; i < n; i++) {
            parent[i] = i;
        }
    }
  
    int find(int x) {
        if (parent[x] != x) {
            parent[x] = find(parent[x]);  // 路径压缩
        }
        return parent[x];
    }
  
    bool unite(int x, int y) {
        int rootX = find(x);
        int rootY = find(y);
      
        if (rootX == rootY) return false;  // 已经在同一集合
      
        // 按秩合并
        if (rank[rootX] < rank[rootY]) {
            parent[rootX] = rootY;
        } else if (rank[rootX] > rank[rootY]) {
            parent[rootY] = rootX;
        } else {
            parent[rootY] = rootX;
            rank[rootX]++;
        }
      
        return true;
    }
};
```

## 🎨 九、图论算法分类总结[5]

### 9.1 图的存储与遍历
- **DFS/BFS**：基础遍历算法
- **应用**：岛屿数量、被围绕的区域

### 9.2 拓扑排序
- **Kahn算法**：基于入度的拓扑排序
- **DFS法**：基于深度优先搜索的拓扑排序
- **应用**：课程表、任务调度

### 9.3 并查集
- **Union-Find**：集合合并与查询
- **应用**：省份数量、朋友圈

### 9.4 最短路径算法
- **Dijkstra**：单源最短路径（非负权）
- **Bellman-Ford**：单源最短路径（可处理负权）
- **Floyd-Warshall**：多源最短路径

### 9.5 最小生成树
- **Kruskal**：基于边的贪心算法
- **Prim**：基于顶点的贪心算法

4. **环的检测**：拓扑排序前需检查是否有环
