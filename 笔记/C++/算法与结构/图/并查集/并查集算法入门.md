# 并查集算法入门

> 本文将通过一道"朋友圈"问题的解决过程，全面剖析并查集算法的原理、实现和常见错误。

## 问题背景

假设我们需要统计一个学校中最大的朋友圈。学校有n个学生，他们参加了m个俱乐部。每个俱乐部的成员互为朋友，朋友的朋友也是朋友。我们需要找出最大的朋友圈人数。

**输入格式**：
- 第一行：n（学生数）和 m（俱乐部数）
- 接下来m行：每行第一个数字k表示俱乐部人数，然后是k个学生编号

## 并查集核心原理

并查集（Disjoint Set Union，DSU）是一种树型数据结构，用于处理一些不交集的合并及查询问题。

### 1. 三个核心操作

```cpp
// 1. 初始化：每个元素自成集合
void init(int n) {
    parent.resize(n);
    for(int i = 0; i < n; i++) parent[i] = i;
}

// 2. 查找：找到元素的根节点（代表元）
int find(int x) {
    if(parent[x] != x) parent[x] = find(parent[x]); // 路径压缩
    return parent[x];
}

// 3. 合并：将两个元素所在集合合并
void unionSets(int x, int y) {
    int rootX = find(x);
    int rootY = find(y);
    if(rootX != rootY) parent[rootX] = rootY;
}
```

### 2. 优化策略

#### 路径压缩（Path Compression）
在`find`操作中，将节点的父节点直接指向根节点，减少树的高度。

#### 按秩合并（Union by Rank）
总是将较小的树连接到较大的树上，保持树的平衡。

```cpp
vector<int> size; // 记录集合大小（只对根节点有效）

void unionSets(int x, int y) {
    int rootX = find(x);
    int rootY = find(y);
    if(rootX == rootY) return;
  
    // 按大小合并
    if(size[rootX] < size[rootY]) {
        parent[rootX] = rootY;
        size[rootY] += size[rootX];
    } else {
        parent[rootY] = rootX;
        size[rootX] += size[rootY];
    }
}
```

## 常见错误分析

### 错误1：合并非根节点

**错误代码**：
```cpp
void make(int x, int y) {
    int x_par = find_par(x);
    int y_par = find_par(y);
  
    if(c_size[x_par] < c_size[y_par]) {
        par[x] = y_par;     // 错误：x可能不是根节点
        c_size[y_par] += c_size[x_par];
    } else {
        par[y] = x_par;     // 错误：y可能不是根节点
        c_size[x_par] += c_size[y_par];
    }
}
```

**问题**：合并操作必须针对根节点进行，否则会破坏树的结构。

**正确代码**：
```cpp
void make(int x, int y) {
    int x_par = find_par(x);
    int y_par = find_par(y);
  
    if(x_par == y_par) return;
  
    if(c_size[x_par] < c_size[y_par]) {
        par[x_par] = y_par;     // 合并根节点
        c_size[y_par] += c_size[x_par];
    } else {
        par[y_par] = x_par;     // 合并根节点
        c_size[x_par] += c_size[y_par];
    }
}
```

### 错误2：= 和 == 混淆

**错误代码**：
```cpp
if(par[i] = i) {  // 这是赋值操作！
    // ...
}
```

**问题**：将比较操作误写为赋值操作，会改变数据结构状态。

**正确代码**：
```cpp
if(par[i] == i) {  // 这才是比较
    // ...
}
```

### 错误3：错误统计集合大小

**错误代码**：
```cpp
for(auto x : c_size) {
    if(x > max) max = x;
}
```

**问题**：`c_size`数组只有在根节点才存储正确的集合大小，非根节点的值不可靠。

**正确代码**：
```cpp
for(int i = 1; i <= n; i++) {
    if(find_par(i) == i) {  // 只有根节点的size才是集合大小
        max = max(max, c_size[i]);
    }
}
```

### 错误4：初始化范围错误

**错误代码**：
```cpp
for(int i = 0; i < n; i++) {
    par[i] = i;
}
```

**问题**：如果学生编号从1开始，应该初始化1~n，而不是0~n-1。

**正确代码**：
```cpp
for(int i = 1; i <= n; i++) {
    par[i] = i;
}
```

## 完整解决方案

```cpp
#include <iostream>
#include <vector>
using namespace std;

class UnionFind {
private:
    vector<int> parent;
    vector<int> size;
  
public:
    UnionFind(int n) {
        parent.resize(n + 1);
        size.resize(n + 1, 1);
        for(int i = 1; i <= n; i++) {
            parent[i] = i;
        }
    }
  
    int find(int x) {
        if(parent[x] != x) {
            parent[x] = find(parent[x]);  // 路径压缩
        }
        return parent[x];
    }
  
    void unite(int x, int y) {
        int rootX = find(x);
        int rootY = find(y);
      
        if(rootX == rootY) return;  // 已在同一集合
      
        // 按大小合并
        if(size[rootX] < size[rootY]) {
            parent[rootX] = rootY;
            size[rootY] += size[rootX];
        } else {
            parent[rootY] = rootX;
            size[rootX] += size[rootY];
        }
    }
  
    int getMaxSize() {
        int maxSize = 0;
        for(int i = 1; i < parent.size(); i++) {
            if(parent[i] == i) {  // 根节点
                maxSize = max(maxSize, size[i]);
            }
        }
        return maxSize;
    }
};

int main() {
    int n, m;
    cin >> n >> m;
  
    UnionFind uf(n);
  
    for(int i = 0; i < m; i++) {
        int k, first;
        cin >> k;
      
        if(k == 0) continue;
      
        cin >> first;
        for(int j = 1; j < k; j++) {
            int student;
            cin >> student;
            uf.unite(first, student);
        }
    }
  
    cout << uf.getMaxSize() << endl;
  
    return 0;
}
```

## 算法复杂度分析

| 操作               | 平均时间复杂度 | 最坏时间复杂度 |
| ------------------ | -------------- | -------------- |
| 初始化             | O(n)           | O(n)           |
| 查找（带路径压缩） | O(α(n))        | O(α(n))        |
| 合并（按秩合并）   | O(α(n))        | O(α(n))        |

其中α(n)是反阿克曼函数，增长极慢，可视为常数。

## 模板代码

```cpp
class DSU {
private:
    vector<int> parent, size;
  
public:
    DSU(int n) {
        parent.resize(n + 1);
        size.resize(n + 1, 1);
        for(int i = 1; i <= n; i++) parent[i] = i;
    }
  
    int find(int x) {
        return parent[x] == x ? x : parent[x] = find(parent[x]);
    }
  
    void unite(int x, int y) {
        x = find(x), y = find(y);
        if(x == y) return;
        if(size[x] < size[y]) swap(x, y);
        parent[y] = x;
        size[x] += size[y];
    }
  
    bool connected(int x, int y) {
        return find(x) == find(y);
    }
  
    int getSize(int x) {
        return size[find(x)];
    }
};
```

## 实战技巧

1. **注意编号起始**：题目编号通常从1开始，数组要开n+1大小
2. **路径压缩一定要写**：`parent[x] = find(parent[x])`不是`return find(parent[x])`
3. **合并前先查**：先find根节点，再比较和合并
4. **大小数组只对根节点有效**：不要用非根节点的size值

## 总结

并查集虽然代码简洁，但实现细节容易出错。关键记住：
- 合并的是根节点，不是任意节点
- 路径压缩在find中完成
- size数组只在根节点有意义
- 注意=和==的区别

掌握这些要点，并查集将成为解决连通性问题的利器。
