# C++ 中的 `class`入门

## 📦 一、什么是类（Class）？

在C++中，**类（Class）** 是一种用户自定义的数据类型，它就像是一个**蓝图**或**模板**，用于创建具有相似特性和行为的**对象**。

### 比喻理解
- **类** = 房子的设计蓝图
- **对象** = 根据蓝图建造的实际房子
- **成员变量** = 房子的属性（面积、房间数、颜色）
- **成员函数** = 房子的功能（开门、关灯、做饭）

## 🔧 二、Graph 类的整体结构

```cpp
class Graph {
private:
    int n;  // 顶点数
    vector<vector<int>> adj;  // 邻接表
    vector<bool> visited;     // 访问标记
  
public:
    // 构造函数
    Graph(int n) : n(n), adj(n), visited(n, false) {}
  
    // 添加边
    void addEdge(int u, int v) { ... }
  
    // 排序邻接表
    void sortAdjLists() { ... }
  
    // DFS遍历
    void DFS(int v, vector<int>& component) { ... }
  
    // BFS遍历
    void BFS(int start, vector<int>& component) { ... }
  
    // 获取连通集
    vector<vector<int>> getComponentsDFS() { ... }
    vector<vector<int>> getComponentsBFS() { ... }
};
```

## 🔍 三、详细解析每个部分

### 3.1 成员变量（数据存储）

```cpp
private:
    int n;                      // 顶点数
    vector<vector<int>> adj;    // 邻接表
    vector<bool> visited;       // 访问标记
```

#### 1. `int n`
- **作用**：存储图中顶点的数量
- **类型**：整数（int）
- **访问权限**：`private`（只能在类内部访问）

#### 2. `vector<vector<int>> adj`
- **作用**：用邻接表存储图的结构
- **类型**：vector的vector（二维动态数组）
- **访问权限**：`private`

**邻接表示例**：
```cpp
// 假设有3个顶点：0,1,2
// 边：0-1, 0-2
adj = {
    {1, 2},  // 顶点0的邻居：1,2
    {0},     // 顶点1的邻居：0
    {0}      // 顶点2的邻居：0
}
```

#### 3. `vector<bool> visited`
- **作用**：记录每个顶点是否已被访问过
- **类型**：bool类型的vector
- **访问权限**：`private`
- **示例**：`visited[0] = true` 表示顶点0已被访问

### 3.2 访问控制：`private` vs `public`

| 关键字    | 作用                       | 示例                | 外部是否能访问 |
| --------- | -------------------------- | ------------------- | -------------- |
| `private` | 私有成员，只能在类内部访问 | `int n;`            | ❌ 不能         |
| `public`  | 公有成员，可以在外部访问   | `void addEdge(...)` | ✅ 能           |

**设计原则**：将数据（成员变量）设为`private`，通过公有方法（成员函数）来操作数据，这称为**封装**。

### 3.3 构造函数

```cpp
public:
    Graph(int n) : n(n), adj(n), visited(n, false) {}
```

**构造函数**：
- **作用**：创建Graph对象时自动调用，用于初始化对象
- **调用时机**：`Graph graph(5);`（创建有5个顶点的图）

**初始化列表**（`:`后面的部分）：
- `n(n)`：将参数n的值赋给成员变量n
- `adj(n)`：创建大小为n的邻接表
- `visited(n, false)`：创建大小为n的visited数组，所有元素初始化为false

### 3.4 成员函数（方法）

#### 1. `addEdge` - 添加边
```cpp
void addEdge(int u, int v) {
    adj[u].push_back(v);
    adj[v].push_back(u);
}
```
- **作用**：在顶点u和v之间添加一条边
- **参数**：两个顶点编号u和v
- **实现**：因为是**无向图**，所以需要在两个方向都添加

#### 2. `sortAdjLists` - 排序邻接表
```cpp
void sortAdjLists() {
    for (int i = 0; i < n; i++) {
        sort(adj[i].begin(), adj[i].end());
    }
}
```
- **作用**：对每个顶点的邻居列表进行排序
- **为什么需要**：题目要求"按编号递增的顺序访问邻接点"
- **算法**：使用C++标准库的`sort`函数

#### 3. `DFS` - 深度优先搜索
```cpp
void DFS(int v, vector<int>& component) {
    visited[v] = true;           // 标记已访问
    component.push_back(v);      // 加入当前连通集
  
    for (int w : adj[v]) {       // 遍历所有邻接点
        if (!visited[w]) {       // 如果未访问
            DFS(w, component);   // 递归访问
        }
    }
}
```
- **作用**：从顶点v开始进行深度优先遍历
- **参数**：
  - `v`：起始顶点
  - `component`：引用参数，用于存储当前连通集的所有顶点
- **关键点**：递归实现，使用系统调用栈

#### 4. `BFS` - 广度优先搜索
```cpp
void BFS(int start, vector<int>& component) {
    queue<int> q;                // 创建队列
    q.push(start);               // 起点入队
    visited[start] = true;       // 标记已访问
  
    while (!q.empty()) {         // 队列不为空时循环
        int v = q.front();       // 取队首
        q.pop();                 // 出队
        component.push_back(v);  // 加入连通集
      
        for (int w : adj[v]) {   // 遍历邻接点
            if (!visited[w]) {   // 如果未访问
                visited[w] = true;  // 标记已访问
                q.push(w);       // 入队
            }
        }
    }
}
```
- **作用**：从顶点start开始进行广度优先遍历
- **关键点**：使用队列，层次遍历

#### 5. `getComponentsDFS/BFS` - 获取所有连通集
```cpp
vector<vector<int>> getComponentsDFS() {
    fill(visited.begin(), visited.end(), false);  // 重置访问标记
    vector<vector<int>> components;
  
    for (int i = 0; i < n; i++) {
        if (!visited[i]) {
            vector<int> component;
            DFS(i, component);
            components.push_back(component);
        }
    }
  
    return components;
}
```
- **作用**：找到图的所有连通分量
- **返回类型**：`vector<vector<int>>`（每个连通集是一个vector）
- **算法**：遍历所有顶点，对每个未访问的顶点进行DFS/BFS

## 🚀 四、如何使用 Graph 类

### 4.1 创建 Graph 对象
```cpp
int n = 5;  // 有5个顶点
Graph graph(n);  // 创建Graph对象
```

**内存中的状态**：
```
graph对象:
  n = 5
  adj = 大小为5的空vector
  visited = [false, false, false, false, false]
```

### 4.2 添加边构建图
```cpp
graph.addEdge(0, 1);  // 添加边0-1
graph.addEdge(0, 2);  // 添加边0-2
graph.addEdge(1, 3);  // 添加边1-3
```

**添加后的邻接表**：
```
adj[0] = {1, 2}
adj[1] = {0, 3}
adj[2] = {0}
adj[3] = {1}
adj[4] = {}  // 顶点4没有边
```

### 4.3 排序邻接表
```cpp
graph.sortAdjLists();
```
**排序后**（保证按编号递增访问）：
```
adj[0] = {1, 2}  // 原本就是递增
adj[1] = {0, 3}  // 原本就是递增
// ...其他不变
```

### 4.4 执行DFS/BFS
```cpp
// 获取DFS连通集
vector<vector<int>> dfsResult = graph.getComponentsDFS();

// 获取BFS连通集
vector<vector<int>> bfsResult = graph.getComponentsBFS();
```

## 🎯 五、类的优势

### 5.1 封装性
```cpp
// 外部只能通过公有方法操作图
graph.addEdge(0, 1);      // ✅ 可以
graph.DFS(0, component);  // ✅ 可以
graph.adj[0] = {...};     // ❌ 不能（adj是private）
```

### 5.2 代码复用
```cpp
// 创建多个不同的图对象
Graph graph1(10);  // 10个顶点的图
Graph graph2(20);  // 20个顶点的图

// 每个对象独立操作，互不影响
graph1.addEdge(0, 1);
graph2.addEdge(5, 6);
```

### 5.3 易于维护
- 图的相关操作都集中在Graph类中
- 修改图实现只需修改类内部代码
- 外部使用方式不变

## 🔄 六、完整使用示例

```cpp
#include <iostream>
#include <vector>
#include <algorithm>
#include <queue>
using namespace std;

// 这里插入Graph类的定义...

int main() {
    // 1. 读取输入
    int n, m;
    cin >> n >> m;
  
    // 2. 创建图对象
    Graph graph(n);
  
    // 3. 添加边
    for (int i = 0; i < m; i++) {
        int u, v;
        cin >> u >> v;
        graph.addEdge(u, v);
    }
  
    // 4. 排序邻接表（重要！）
    graph.sortAdjLists();
  
    // 5. 获取并输出DFS结果
    cout << "DFS连通集:" << endl;
    vector<vector<int>> dfsComponents = graph.getComponentsDFS();
    for (const auto& component : dfsComponents) {
        cout << "{ ";
        for (int v : component) {
            cout << v << " ";
        }
        cout << "}" << endl;
    }
  
    // 6. 获取并输出BFS结果
    cout << "\nBFS连通集:" << endl;
    vector<vector<int>> bfsComponents = graph.getComponentsBFS();
    for (const auto& component : bfsComponents) {
        cout << "{ ";
        for (int v : component) {
            cout << v << " ";
        }
        cout << "}" << endl;
    }
  
    return 0;
}
```

**输入示例**：
```
8 6
0 7
0 1
2 0
4 1
2 4
3 5
```

**输出示例**：
```
DFS连通集:
{ 0 1 4 2 7 }
{ 3 5 }
{ 6 }

BFS连通集:
{ 0 1 2 7 4 }
{ 3 5 }
{ 6 }
```

## 💡 七、C++语法要点

### 7.1 构造函数初始化列表
```cpp
Graph(int n) : n(n), adj(n), visited(n, false) {}
```
- **作用**：在对象创建时初始化成员变量
- **语法**：`:`后面跟初始化列表
- **优势**：比在构造函数体内赋值更高效

### 7.2 引用参数 `&`
```cpp
void DFS(int v, vector<int>& component)
```
- **作用**：`component`是引用，不是副本
- **效果**：函数内修改`component`会影响外部传入的变量
- **优势**：避免复制整个vector，提高效率

### 7.3 `const` 引用
```cpp
for (const auto& component : dfsComponents)
```
- **作用**：`const`表示不修改component，`&`表示引用
- **优势**：高效且安全（不能意外修改）

### 7.4 范围for循环
```cpp
for (int w : adj[v])  // C++11引入的语法
```
- **作用**：遍历容器中的所有元素
- **等价于**：
```cpp
for (int i = 0; i < adj[v].size(); i++) {
    int w = adj[v][i];
    // ...
}
```

## 📚 九、学习建议

### 9.1 理解面向对象思想
1. **类 = 数据类型**：就像`int`、`string`一样，可以自定义
2. **对象 = 变量**：根据类创建的具体实例
3. **方法 = 操作**：对象可以执行的操作

### 9.2 动手实践
1. **逐行理解**：读懂Graph类的每一行代码
2. **手动模拟**：在纸上画图，模拟类的工作过程
3. **修改扩展**：尝试添加新功能到Graph类
4. **调试运行**：使用调试器查看对象内部状态

### 9.3 常见错误
```cpp
// 错误1：忘记调用构造函数
Graph graph;  // ❌ 错误：需要参数
Graph graph(10);  // ✅ 正确

// 错误2：直接访问private成员
graph.n = 5;  // ❌ 错误：n是private
graph.addEdge(0, 1);  // ✅ 正确：通过公有方法

// 错误3：忘记排序邻接表
graph.sortAdjLists();  // ✅ 必须调用，否则访问顺序可能错误
```

## 总结

这个`class Graph { ... }`是一个完整的图数据结构的C++实现，它：

1. **封装了图的表示和操作**：将顶点数、邻接表、访问标记等数据，以及DFS、BFS等操作封装在一起
2. **提供了清晰的接口**：通过公有方法暴露必要的操作，隐藏实现细节
3. **遵循面向对象原则**：数据私有化，通过方法访问
4. **解决了具体问题**：专门为"列出连通集"问题设计，但可以轻松扩展
