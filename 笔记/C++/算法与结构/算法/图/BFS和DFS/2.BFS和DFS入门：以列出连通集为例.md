# BFS和DFS入门：以"列出连通集"为例

## 一、图的基本概念

首先，我们来理解什么是图。在生活中，很多关系可以用图来表示：
- **社交网络**：每个人是**顶点**，好友关系是**边**
- **地图导航**：每个路口是**顶点**，道路是**边**
- **本题中的图**：有n个顶点（编号0到n-1），m条边连接这些顶点

**关键术语**：
- **顶点（Vertex/Node）**：图中的点，本题中编号为0,1,2,...,n-1
- **边（Edge）**：连接两个顶点的线，表示它们之间的关系
- **无向图**：边没有方向，A-B和B-A是相同的
- **连通集**：相互可达的顶点集合。比如：{0,1,4,2,7}是一个连通集，这些顶点相互连通

## 二、DFS（深度优先搜索）详解

### 比喻理解
想象你在一个迷宫中探索：
1. 选择一条路一直走到底（深度优先）
2. 走到死胡同就**回溯**到上一个岔路口
3. 选择另一条未走过的路继续探索
4. 重复直到所有路都走过

### 核心思想
- **深度优先**：一条路走到黑，不撞南墙不回头
- **使用栈**：递归的本质就是使用系统栈
- **回溯**：遇到无法继续时返回上一级

### DFS遍历过程（以样例为例）
```
图结构：
顶点：0-1-4-2-7 构成一个连通集
顶点：3-5 构成一个连通集
顶点：6 单独一个连通集

从最小顶点0开始DFS：
1. 访问0 → {0}
2. 从0出发，最小邻接点是1 → {0,1}
3. 从1出发，最小邻接点是4 → {0,1,4}
4. 从4出发，最小邻接点是2 → {0,1,4,2}
5. 从2出发，最小邻接点是7 → {0,1,4,2,7}
6. 回溯，发现所有顶点都已访问
```

### DFS递归实现（伪代码）
```cpp
void DFS(int v) {
    visited[v] = true;      // 标记已访问
    result.push_back(v);    // 加入结果
  
    // 按编号递增顺序访问邻接点
    for (每个与v相邻的顶点w) {
        if (!visited[w]) {  // 如果未访问
            DFS(w);         // 递归访问
        }
    }
}
```

## 三、BFS（广度优先搜索）详解

### 比喻理解
想象水面上的涟漪：
1. 从起点开始，像涟漪一样**一层层**向外扩散
2. 先访问所有距离为1的顶点（直接邻居）
3. 再访问所有距离为2的顶点（邻居的邻居）
4. 依此类推

### 核心思想
- **广度优先**：一层层扩展，先近后远
- **使用队列**：先进先出（FIFO）
- **层次遍历**：按距离起点的远近顺序访问

### BFS遍历过程（以样例为例）
```
同样从最小顶点0开始BFS：
1. 访问0 → {0}
2. 访问0的所有邻居（按编号排序）：1,2,7 → {0,1,2,7}
3. 访问1的未访问邻居：4 → {0,1,2,7,4}
4. 队列为空，结束
```

### BFS队列实现（伪代码）
```cpp
void BFS(int start) {
    queue<int> q;
    q.push(start);
    visited[start] = true;
  
    while (!q.empty()) {
        int v = q.front();
        q.pop();
        result.push_back(v);
      
        // 按编号递增顺序访问邻接点
        for (每个与v相邻的顶点w) {
            if (!visited[w]) {
                visited[w] = true;
                q.push(w);
            }
        }
    }
}
```

## 四、DFS vs BFS 对比

| 特性           | DFS（深度优先）            | BFS（广度优先）       |
| -------------- | -------------------------- | --------------------- |
| **数据结构**   | 栈（递归/显式栈）          | 队列                  |
| **访问顺序**   | 深度优先，一条路到底       | 广度优先，一层层扩展  |
| **空间复杂度** | O(h)，h为最大深度          | O(w)，w为最宽层的宽度 |
| **适用场景**   | 找路径、拓扑排序、回溯问题 | 最短路径、层次遍历    |
| **本题结果**   | {0 1 4 2 7}                | {0 1 2 7 4}           |

**关键区别**：
- DFS：0→1→4→2→7（深入探索）
- BFS：0→1→2→7→4（层次扩展）

## 五、解题思路分析

### 题目要求理解
1. **输入**：n个顶点，m条边，构建无向图
2. **遍历要求**：
   - 从**编号最小**的未访问顶点开始
   - 按**编号递增**顺序访问邻接点
3. **输出**：
   - 先输出所有DFS连通集
   - 再输出所有BFS连通集
   - 每个连通集格式：`{ v1 v2 ... vk }`

### 解题步骤
1. **建图**：使用邻接表存储图
2. **排序邻接表**：保证按编号递增访问
3. **DFS遍历**：
   - 对每个未访问的顶点进行DFS
   - 每次DFS得到一个连通集
4. **BFS遍历**：
   - 重置访问标记
   - 对每个未访问的顶点进行BFS
   - 每次BFS得到一个连通集

## 六、完整C++代码实现

```cpp
#include <iostream>
#include <vector>
#include <algorithm>
#include <queue>
using namespace std;

class Graph {
private:
    int n;  // 顶点数
    vector<vector<int>> adj;  // 邻接表
    vector<bool> visited;     // 访问标记
  
public:
    Graph(int n) : n(n), adj(n), visited(n, false) {}
  
    // 添加边（无向图）
    void addEdge(int u, int v) {
        adj[u].push_back(v);
        adj[v].push_back(u);
    }
  
    // 对邻接表排序，保证按编号递增访问
    void sortAdjLists() {
        for (int i = 0; i < n; i++) {
            sort(adj[i].begin(), adj[i].end());
        }
    }
  
    // DFS递归实现
    void DFS(int v, vector<int>& component) {
        visited[v] = true;
        component.push_back(v);
      
        // 按编号递增顺序访问邻接点
        for (int w : adj[v]) {
            if (!visited[w]) {
                DFS(w, component);
            }
        }
    }
  
    // 获取所有连通集（DFS）
    vector<vector<int>> getComponentsDFS() {
        fill(visited.begin(), visited.end(), false);  // 重置访问标记
        vector<vector<int>> components;
      
        // 从编号最小的未访问顶点开始
        for (int i = 0; i < n; i++) {
            if (!visited[i]) {
                vector<int> component;
                DFS(i, component);
                components.push_back(component);
            }
        }
      
        return components;
    }
  
    // BFS实现
    void BFS(int start, vector<int>& component) {
        queue<int> q;
        q.push(start);
        visited[start] = true;
      
        while (!q.empty()) {
            int v = q.front();
            q.pop();
            component.push_back(v);
          
            // 按编号递增顺序访问邻接点
            for (int w : adj[v]) {
                if (!visited[w]) {
                    visited[w] = true;
                    q.push(w);
                }
            }
        }
    }
  
    // 获取所有连通集（BFS）
    vector<vector<int>> getComponentsBFS() {
        fill(visited.begin(), visited.end(), false);  // 重置访问标记
        vector<vector<int>> components;
      
        // 从编号最小的未访问顶点开始
        for (int i = 0; i < n; i++) {
            if (!visited[i]) {
                vector<int> component;
                BFS(i, component);
                components.push_back(component);
            }
        }
      
        return components;
    }
};

int main() {
    int n, m;
    cin >> n >> m;
  
    Graph graph(n);
  
    // 读入边
    for (int i = 0; i < m; i++) {
        int u, v;
        cin >> u >> v;
        graph.addEdge(u, v);
    }
  
    // 对邻接表排序，保证按编号递增访问
    graph.sortAdjLists();
  
    // 获取并输出DFS连通集
    vector<vector<int>> dfsComponents = graph.getComponentsDFS();
    for (const auto& component : dfsComponents) {
        cout << "{ ";
        for (int v : component) {
            cout << v << " ";
        }
        cout << "}" << endl;
    }
  
    // 获取并输出BFS连通集
    vector<vector<int>> bfsComponents = graph.getComponentsBFS();
    for (const auto& component : bfsComponents) {
        cout << "{ ";
        for (int v : component) {
            cout << v << " ";
        }
        cout << "}" << endl;
    }
  
    return 0;
}
```

## 七、代码逐行解释

### 1. 图的数据结构
```cpp
class Graph {
private:
    int n;  // 顶点数
    vector<vector<int>> adj;  // 邻接表
    vector<bool> visited;     // 访问标记
```
- `n`：顶点数量
- `adj`：邻接表，`adj[i]`存储与顶点i相邻的所有顶点
- `visited`：记录每个顶点是否已被访问

### 2. 添加边（无向图）
```cpp
void addEdge(int u, int v) {
    adj[u].push_back(v);
    adj[v].push_back(u);  // 无向图需要添加双向边
}
```

### 3. 排序邻接表（关键！）
```cpp
void sortAdjLists() {
    for (int i = 0; i < n; i++) {
        sort(adj[i].begin(), adj[i].end());
    }
}
```
**为什么需要排序？**
题目要求：按编号递增的顺序访问邻接点。如果不排序，访问顺序可能不符合要求。

### 4. DFS递归实现
```cpp
void DFS(int v, vector<int>& component) {
    visited[v] = true;           // 标记已访问
    component.push_back(v);      // 加入当前连通集
  
    for (int w : adj[v]) {       // 遍历所有邻接点
        if (!visited[w]) {       // 如果未访问
            DFS(w, component);   // 递归访问
        }
    }
}
```
**递归过程**：
1. 访问当前顶点v
2. 将其加入连通集
3. 对其所有未访问的邻接点递归调用DFS
4. 自动实现"回溯"

### 5. BFS队列实现
```cpp
void BFS(int start, vector<int>& component) {
    queue<int> q;                // 创建队列
    q.push(start);               // 起点入队
    visited[start] = true;       // 标记已访问
  
    while (!q.empty()) {         // 队列不为空时循环
        int v = q.front();       // 取队首
        q.pop();                 // 出队
        component.push_back(v);  // 加入连通集
      
        for (int w : adj[v]) {   // 遍历邻接点
            if (!visited[w]) {   // 如果未访问
                visited[w] = true;  // 标记已访问
                q.push(w);       // 入队
            }
        }
    }
}
```
**队列操作**：
- `push()`：入队
- `front()`：查看队首
- `pop()`：出队
- `empty()`：判断队列是否为空

### 6. 主函数流程
```cpp
int main() {
    // 1. 读入n,m
    // 2. 创建图对象
    // 3. 添加边
    // 4. 排序邻接表（重要！）
    // 5. 获取并输出DFS结果
    // 6. 获取并输出BFS结果
}
```

## 九、常见问题解答

### Q1: 为什么DFS和BFS的结果顺序不同？
A: 因为遍历策略不同：
- DFS：0→1→4→2→7（深度优先，一条路走到底）
- BFS：0→1→2→7→4（广度优先，一层层扩展）

### Q2: 如何保证从编号最小的顶点开始？
A: 主循环中从`i=0`开始检查，第一个未访问的顶点就是编号最小的。

### Q3: 为什么要排序邻接表？
A: 题目明确要求"按编号递增的顺序访问邻接点"。如果不排序，访问顺序可能随机。

### Q4: 递归的DFS会栈溢出吗？
A: 本题n≤10，递归深度很小，不会溢出。如果n很大，可以使用显式栈。

### Q5: 无向图和有向图的区别？
A: 无向图的边是双向的，添加边时需要`adj[u].push_back(v)`和`adj[v].push_back(u)`。
