# 退格字符串比较：三种解法从暴力到最优

## 问题描述

给定两个字符串 `s` 和 `t`，其中字符 `#` 表示退格键（删除前一个字符）。判断这两个字符串在文本编辑器中编辑后是否相等。

**示例**：
- `s = "ab#c"`, `t = "ad#c"` → 都变成 `"ac"`，返回 `true`
- `s = "a#c"`, `t = "b"` → `s` 变成 `"c"`，`t` 保持 `"b"`，返回 `false`

**进阶要求**：使用 O(n) 时间复杂度和 O(1) 空间复杂度解决。

---

## 解法一：栈方法（直观解法）

### 思路分析
这是最直观的解法：模拟文本编辑器的行为。我们遍历每个字符：
- 如果是普通字符，压入栈中
- 如果是 `#`，弹出栈顶元素（如果栈非空）

### 代码实现
```cpp
class Solution {
public:
    bool backspaceCompare(string s, string t) {
        return processString(s) == processString(t);
    }
  
private:
    string processString(const string& str) {
        string result;
        for (char ch : str) {
            if (ch != '#') {
                result.push_back(ch);
            } else if (!result.empty()) {
                result.pop_back();
            }
        }
        return result;
    }
};
```

### 复杂度分析
- **时间复杂度**：O(m + n)，需要分别处理两个字符串
- **空间复杂度**：O(m + n)，需要使用额外的栈空间存储结果

---

## 解法二：双指针法（最优解法）

### 核心洞察
一个字符是否会被删除，**只取决于它后面的退格符**。因此我们可以从字符串末尾开始向前处理，这样可以立即知道当前字符是否需要保留。

### 算法步骤
1. 使用两个指针分别从 `s` 和 `t` 的末尾开始
2. 维护两个计数器记录需要跳过的字符数（遇到 `#` 时增加）
3. 每次找到两个字符串中下一个应该比较的字符
4. 比较这两个字符，如果不相等则返回 false
5. 如果遍历完所有字符都相等，返回 true

### 代码实现
```cpp
class Solution {
public:
    bool backspaceCompare(string s, string t) {
        int i = s.length() - 1, j = t.length() - 1;
        int skipS = 0, skipT = 0;
      
        while (i >= 0 || j >= 0) {
            // 在 s 中找到下一个有效的字符
            while (i >= 0) {
                if (s[i] == '#') {
                    skipS++;
                    i--;
                } else if (skipS > 0) {
                    skipS--;
                    i--;
                } else {
                    break;
                }
            }
          
            // 在 t 中找到下一个有效的字符
            while (j >= 0) {
                if (t[j] == '#') {
                    skipT++;
                    j--;
                } else if (skipT > 0) {
                    skipT--;
                    j--;
                } else {
                    break;
                }
            }
          
            // 比较两个字符
            if (i >= 0 && j >= 0) {
                if (s[i] != t[j]) {
                    return false;
                }
            } else if (i >= 0 || j >= 0) {
                // 一个字符串已经遍历完，另一个还有字符
                return false;
            }
          
            i--;
            j--;
        }
      
        return true;
    }
};
```

### 复杂度分析
- **时间复杂度**：O(m + n)，每个字符最多被访问一次
- **空间复杂度**：O(1)，只使用了常数个变量

---

## 解法三：原地修改法（空间优化的栈）

### 思路分析
我们可以利用字符串本身作为栈，使用一个栈顶指针来模拟栈的操作。这种方法避免了额外的字符串构建，直接在原字符串上操作。

### 算法步骤
1. 使用两个指针分别作为 `s` 和 `t` 的栈顶
2. 遍历字符串：
   - 遇到普通字符：放入栈顶位置，栈顶指针+1
   - 遇到 `#`：如果栈非空，栈顶指针-1
3. 比较两个字符串的前 `栈顶指针` 个字符

### 代码实现
```cpp
class Solution {
public:
    bool backspaceCompare(string s, string t) {
        int s_top = 0, t_top = 0;
      
        // 处理字符串 s
        for (int i = 0; i < s.size(); i++) {
            if (s[i] != '#') {
                s[s_top++] = s[i];
            } else if (s_top > 0) {
                s_top--;
            }
        }
      
        // 处理字符串 t
        for (int i = 0; i < t.size(); i++) {
            if (t[i] != '#') {
                t[t_top++] = t[i];
            } else if (t_top > 0) {
                t_top--;
            }
        }
      
        // 如果长度不同，直接返回 false
        if (s_top != t_top) return false;
      
        // 逐个比较字符
        for (int i = 0; i < s_top; i++) {
            if (s[i] != t[i]) return false;
        }
      
        return true;
    }
};
```

### 复杂度分析
- **时间复杂度**：O(m + n)，每个字符处理一次
- **空间复杂度**：O(1)，原地修改，不使用额外空间

## 三种解法对比

| 特性             | 栈方法 | 双指针法 | 原地修改法 |
| ---------------- | ------ | -------- | ---------- |
| 时间复杂度       | O(m+n) | O(m+n)   | O(m+n)     |
| 空间复杂度       | O(m+n) | O(1)     | O(1)       |
| 是否修改原字符串 | 否     | 否       | 是         |
| 实现难度         | 简单   | 中等     | 简单       |
| 可读性           | 高     | 中       | 中         |

## 关键知识点

### 1. 栈的应用
栈是处理"最近相关性"问题的利器，退格键正是需要处理最近输入的字符。

### 2. 双指针技巧
从后向前遍历可以避免"前瞻"问题，因为退格符只影响前面的字符。

### 3. 原地算法
当允许修改输入数据时，使用原数组作为存储空间可以大幅减少空间使用。

### 4. 边界情况处理
- 连续多个退格符：`"a##b"` → `"b"`
- 退格符多于字符：`"a###"` → `""`
- 空字符串：`""` → `""`

## 常见错误

### 错误1：从前向后处理时的前瞻问题
```cpp
// 错误代码：无法处理连续退格
for (int i = 0; i < s.length(); i++) {
    if (s[i] == '#') {
        // 这里需要删除前一个字符，但前一个字符可能已经被删除
    }
}
```

### 错误2：忽略退格符在开头的情况
```cpp
// 错误代码：栈空时仍尝试弹出
if (ch == '#') {
    stack.pop_back();  // 如果栈为空，这里会出错
}
```

### 错误3：比较未处理完的字符串
```cpp
// 错误代码：直接比较原字符串
return s == t;  // 没有处理退格符
```

## 总结

退格字符串比较问题展示了同一问题的多种解法，体现了算法设计的渐进优化过程：

1. **栈方法**：最直观，适合面试快速实现
2. **双指针法**：满足进阶要求，体现算法思维
3. **原地修改法**：空间最优，但会修改输入数据

**选择建议**：
- 面试中可以先给出栈解法，再优化到双指针解法
- 在实际工程中，如果不允许修改原数据，使用双指针法
- 如果内存极度受限，使用原地修改法

for (char ch : str) {

    }

这段代码是**退格字符串处理**的核心逻辑，它模拟了文本编辑器中退格键的行为。让我们逐层深入分析。

---

### 1. 范围for循环：`for (char ch : str)`

### 语法解析
这是C++11引入的**范围for循环**（range-based for loop），语法更简洁、更安全。

```cpp
// 等价于传统循环：
for (size_t i = 0; i < str.size(); i++) {
    char ch = str[i];
    // ... 循环体
}
```

### 工作原理
1. **自动遍历**：自动遍历`str`中的每个字符
2. **自动类型推导**：`char ch`声明循环变量，编译器自动推导类型
3. **自动边界检查**：不会越界访问，更安全
4. **只读访问**：默认是值拷贝，不会修改原字符串

### 与传统循环对比

| 特性       | 范围for循环 | 传统for循环 |
| ---------- | ----------- | ----------- |
| 语法简洁性 | ★★★★★       | ★★★☆☆       |
| 安全性     | ★★★★★       | ★★★☆☆       |
| 性能       | 相当        | 相当        |
| 需要索引时 | 不方便      | 方便        |

---

### 2. 条件判断逻辑

### 第一层判断：`if (ch != '#')`
```cpp
if (ch != '#') {
    result.push_back(ch);
}
```

**含义**：
- 如果当前字符**不是退格符**（`#`）
- 将其视为**有效字符**，添加到结果字符串末尾

**示例**：
```cpp
str = "abc"
处理过程：
ch='a' → result="a"
ch='b' → result="ab"
ch='c' → result="abc"
```

### 第二层判断：`else if (!result.empty())`
```cpp
else if (!result.empty()) {
    result.pop_back();
}
```

**含义**：
- `else if`：只有当前字符是`#`时才会执行
- `!result.empty()`：检查结果字符串**是否非空**
- 如果非空，删除最后一个字符（模拟退格）

**关键点**：
1. **防御性编程**：先检查是否为空，避免空字符串调用`pop_back()`
2. **逻辑完备**：只有非空时才执行退格操作
